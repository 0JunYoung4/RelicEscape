# 하단 B파트 · 수평 레일과 방패병 회랑

A파트 왼쪽 출구를 통과하면 B 오른쪽 발판으로 이어진다. 약 두 화면 분량이며, 오른쪽에서 왼쪽으로 진행해 C 진입부에 닿는다. [사각형 배치도](map1-lower-route-b-blockout-v1.png) · [미술 시안](../assets/concepts/map1-lower-route-b-v1.png)

| 순서 | 플레이 흐름 |
| --- | --- |
| 1. A 연결 발판 | 적 없이 잠깐 이동한다. 레일 출발대 근처에서 건너편 석등과 정차점이 한 화면에 보이도록 시야를 잡는다. |
| 2. 수평 레일 | 오른쪽 파츠에 E로 장착하고 왼쪽을 보며 X로 친다. 파츠가 맞은편 발판 위에 닿으면 E로 이동한다. 석등이 있는 안전한 착지점에서 유물을 다시 손에 쥔다. |
| 3. 방패병 회랑 | 낮은 디딤돌부터 높은 발판을 밟아 방패병을 넘을 수 있다. 싸우려면 오른쪽에 유물을 두고 왼쪽으로 넘어간다. 방패병이 왼쪽 공격을 준비할 때 E로 복귀해 등 뒤를 노린다. 위쪽으로 지나가는 길도 열려 있다. |
| 4. C 연결 | 떨어진 위치에 배치한 공벌레 한 마리를 지나면 짧은 안전 통로로 이어진다. 왼쪽 석등을 지나 C파트로 들어간다. |

## 떨어졌을 때

파츠가 아직 협곡 위에 있을 때 E를 눌러도 아래의 평평한 안전 바닥이 받아준다. 오른쪽 4단을 차례로 올라 출발대에서 회수 손잡이를 E로 작동하면 파츠가 돌아온다. 유물이 장착돼 있으면 함께 회수한다. 다른 곳에 둔 유물은 기존 E 복귀로 회수할 수 있다. 아래층 왼쪽은 발판이 길게 돌출돼 출구를 바로 오를 수 없고, 오른쪽 계단은 출발대로 연결된다.

## 배치 초안

원점은 C쪽 바닥, 높이는 위로 갈수록 커진다. 아래 값은 세계 좌표 초안이며 사각형 배치도에 반영했다.

| 항목 | 치수 및 조건 |
| --- | --- |
| 전체 | `x=0~4200`, 연결 바닥 `y=0`. A쪽은 오른쪽, C쪽은 왼쪽. |
| 협곡 | 왼쪽 끝 `x=2250`, 오른쪽 끝 `x=3260`. 같은 높이에서 폭 1,010으로 현재 달리기 점프의 이론상 거리 약 518보다 넓다. |
| 레일 | 중심은 오른쪽 `(3430,100)`부터 왼쪽 `(2070,100)`까지. 현행 속도 660에서 약 2.06초. 유물 순간이동 후 발은 바닥보다 30 높고, 왼쪽 착지점에서 협곡 끝까지 180의 여유가 있다. 레일 경로는 왼쪽에서 오른쪽 순으로 정의하고 파츠는 오른쪽 종점에서 시작해, 왼쪽 타격으로 되감기 방향으로 보낸다. |
| 회수로 | 바닥 `y=-595`. 오른쪽으로 `y=-475, -355, -235, -115`를 거쳐 `y=0`으로 올라온다. 왼쪽 안벽 `x=1660`부터 발판 끝까지 590이고 밑면에는 올라설 턱을 만들지 않는다. |
| 전투 발판 | 오른쪽부터 바닥에 붙은 디딤돌 `y=110`, 공중 발판 `y=225, 315, 200`. 올라가는 단차는 최대 115, 높아진 발판 아래에는 통과 높이를 둔다. |
| 몬스터 | 방패병은 `x≈1150`에서 오른쪽을 바라본다. 유물은 `x≈1360`에 둘 수 있다. 공벌레는 `x≈650` 근처, 안전 연결부는 `x≤390`. |

방패병은 기존 방패 막기·밀치기 자산을 활용할 예정이다. 후면 공격이 성립하도록 밀치기 예고부터 짧은 회복 구간까지 방패 방향을 고정하는 동작을 제안한다. 그 지속 시간, 위쪽 점프의 실제 궤적, 회수로 왼쪽의 벽점프 우회 여부는 플레이 가능한 배치에서 검증한다.

## 미술 배치

A의 청록 동굴에 이어 부서진 수로의 기둥, 육각 문양을 새긴 돌 조각, 원경 폭포를 둔다. 황금빛 석등은 협곡 건너편 착지점과 C쪽 방향을 알려준다. 암벽 외곽은 불규칙한 다각형으로 만들고, 발판 윗면에만 얇은 이끼선을 남긴다. 배경 아치는 대비를 낮춰 실제 발판과 구분한다.

내장 image_gen으로 [기본 환경 이미지](../assets/concepts/map1-lower-route-b-v1-plate.png)를 제작했다. HK-GP18의 암반 실루엣과 이끼 경계, HK-GP22의 불규칙한 발판 밑면, HK-CT-05의 유적 뒤쪽 깊이를 참고했다. [생성·수정 프롬프트](../assets/concepts/map1-lower-route-b-v1.prompt.txt)

전체 시안에는 테스트룸에서 쓰는 직선 레일과 장착 파츠, 원본 방패병·공벌레 스프라이트를 SDL로 배치했다. 지형, 충돌, 적 행동은 아직 본편에 연결하지 않은 상태다.

사각형 도면은 `.\.venv\Scripts\python.exe tools/draw_lower_route_b.py`로 다시 만들 수 있다. 미술 시안의 위치와 비율은 대략적인 연출 기준이다.
