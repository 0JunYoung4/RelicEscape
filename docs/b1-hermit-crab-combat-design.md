# B1 바위 소라게 전투 설계

맵 1의 첫 보스전이다. 첫 교전에서 집게 내려찍기와 점프 낙하의 전조와 반격을 익힌다. 소라게가 등딱지에 숨으면 유물 레일로 상단에 올라가 천장 암석을 떨어뜨린다. 다시 깨어난 뒤에는 같은 낙하를 두 번 연결해 안전한 반격 시점을 판단하게 한다. 체력 기준, 연계 순서, 새로 정한 시간은 첫 플레이테스트 가안이다.

## 행동트리

```text
B1 전투 [우선순위 선택]
├─ 플레이어 사망 → 진행 중인 연출·판정 해제 → C 전실 석등 복귀
├─ 보스 체력 0 → 격파 확정 → 남은 공격 판정 해제 → 오른쪽 봉인문 개방
├─ 도입 [순서]
│  ├─ 방 중앙의 등딱지 앞에서 ‘E 조사’ 대기
│  ├─ 조사 입력 소비 → 화면 진동 · 시야 확대 · 낙진
│  ├─ 도입 암석 충돌 → 소라게가 눈을 뜸 → 입구 석문 닫힘
│  └─ 포효 재생 → 전투 자세 · 조작 복귀 → 1페이즈
├─ 1페이즈 · 기본기 [순서]
│  ├─ 집게 내려찍기 → 회복
│  ├─ 단발 점프 낙하 → 회복
│  ├─ 체력 50%까지 반복 [공격과 회복을 한 묶음으로 실행]
│  │  ├─ 같은 공격을 연속 두 번 사용 → 다른 공격
│  │  ├─ 집게 사거리 안 → 집게 내려찍기
│  │  └─ 그 외 → 단발 점프 낙하
│  └─ 마지막 회복 완료 → 2페이즈
├─ 2페이즈 · 등딱지 은신 [순서]
│  ├─ 중앙 이동 → 제자리 집게 내려찍기 → 등딱지에 숨기
│  ├─ 유물 레일 활성화 → 플레이어의 천장 암석 타격 대기
│  ├─ 떨어진 암석이 등딱지와 충돌 → 방어 해제
│  └─ 플레이어가 전투 바닥에 착지 → 얼굴 노출 1.20초 → 3페이즈
└─ 3페이즈 · 연속 낙하 [반복]
   └─ 집게 → 단발 낙하 → 집게 → 2연속 낙하
```

- **선택과 진행.** 위에서부터 사망·격파를 판정한 뒤 현재 페이즈의 가지를 실행한다. 순서 노드는 진행 중인 자식과 경과 시간을 기억한다. 조사 입력이나 암석 충돌을 기다리는 동안에는 진행 중 상태를 유지한다. 예고 도중 거리 조건이 바뀌거나 체력 50%에 닿아도 이미 시작한 공격은 회복까지 이어진다. 사망과 격파가 같은 프레임에 발생하면 재도전으로 처리하는 가안을 둔다.
- **입력과 연출의 경계.** 조사 입력 `E`는 플레이어가 바닥에서 등딱지 앞 조사 범위에 들어왔을 때만 접수한다. 성공한 입력은 조사에 한 번만 쓰고 레일·유물 처리로 넘기지 않는다. 범위 밖 입력에는 기존 조작을 적용한다. 첫 테스트에서는 연출 동안 이동·공격·유물 입력을 잠그고 피해 판정을 끈다. 포효가 끝나면 입력을 복구하고 첫 집게가 전조를 낸다.
- **전투 종료.** 사망 시 진행 중인 카메라 진동, 공격 범위, 타이머를 정리하고 다음 시도를 도입부터 시작한다. 격파 시 진행 봉인문을 한 번만 열고, 방에 다시 들어와도 조사와 전투는 재시작하지 않는다.

조사·진동은 기존 3.20초 시안, 포효는 기존 2초 애니메이션을 기준으로 잡았다. 진동은 카메라에만 적용해 지형과 충돌 좌표를 고정한다. 도입 암석은 은신 해제용 중앙 천장 암석과 별개이며, 중앙 암석은 2페이즈까지 매달려 있다. [조사·진동 시안](../tools/preview_b1_intro.py) · [포효 자세와 타이밍](../assets/concepts/b1-hermit-crab/roar-v4/README.md)

## 페이즈와 전환

| 구간 | 진행 | 전환 조건 |
| --- | --- | --- |
| 도입 | 오른쪽 통로로 입장한 뒤 등딱지 앞에서 `E`로 조사한다. 화면 진동과 낙진, 도입 암석 충돌과 입구 석문 닫힘, 2초 포효가 이어진다. | 소라게가 전투 자세를 되찾으면 첫 집게 공격을 시작한다. [분리 효과](../assets/concepts/b1-hermit-crab/roar-v1/README.md) |
| 1페이즈 · 두 공격 학습 | 첫 두 공격은 **집게 내려찍기 → 단발 점프 낙하** 순으로 보여 준다. 이후 집게가 닿는 거리에서는 집게, 거리가 멀면 낙하를 우선한다. 한 공격을 두 번 연속 썼으면 다음에는 다른 공격을 고른다. | 첫 두 공격을 마쳤고 체력이 50%에 도달하면, 진행 중인 공격과 반격 시간을 마친 뒤 중앙으로 이동해 2페이즈에 진입한다. 은신 해제 전까지 체력 하한은 50%다. |
| 2페이즈 · 등딱지 은신 | 중앙에서 집게 내려찍기 한 번으로 전환을 알린다. 타격 직후 팔다리와 얼굴을 접어 등딱지에 숨고 레일이 켜진다. 유물 레일 → 바깥쪽 긴 발판 → 안쪽 짧은 발판 → 중앙 천장 암석 타격 순으로 진행한다. | 암석이 등딱지에 닿으면 방어가 풀린다. 소라게가 몸을 펴고 기다렸다가 플레이어가 바닥에 안전하게 착지하면 3페이즈가 시작된다. |
| 3페이즈 · 낙하 연계 | 재등장 직후 몸을 낮춘 동안 첫 반격이 가능하다. 이후 **집게 → 단발 낙하 → 집게 → 2연속 낙하**를 반복한다. 집게는 기존처럼 옆걸음으로 접근한 뒤 제자리에서 전조를 낸다. | 남은 체력을 모두 깎으면 전투를 마친다. 보스와 공격의 피해 판정을 끄고, 맵 1의 기존 처치 조건으로 오른쪽 봉인문을 연다. |

첫 페이즈의 50% 도달 타격은 정상 명중으로 처리한다. 이 타격 뒤에는 얼굴을 낮추고 등딱지 표면에 방어 피드백을 준다. 예정된 회복이 끝나면 중앙으로 이동한다. 중앙 집게는 얼굴을 접는 동작으로 바로 이어져 일반 집게의 반격 자세와 구별된다. 집게가 닿지 않는 곳에 있는 플레이어를 따라 중앙을 벗어나지 않는다.

## 공격 전조와 반격

집게는 **접근 → 방향 고정 → 전조 → 타격 → 회복** 순서로 실행한다. 낙하는 **발구름 → 화면 밖 대기 → 목표 고정 → 예고 → 착지**를 공통 가지로 쓴다. 단발은 한 번 착지한 뒤, 2연속은 같은 가지를 두 번 실행한 뒤 회복을 연다. 두 번째 낙하의 목표는 두 번째 예고가 시작될 때 다시 잡는다.

반격 시간은 공격의 피해 판정이 끝난 뒤부터 잰다. 전조를 보고 기본 이동으로 타격을 피한 자리에서, 반격 시간 안에 다가가 기본 베기 한 번을 넣을 수 있어야 한다. 다음 공격의 피해는 새 전조를 거친 뒤에 발생한다.

| 공격 | 전조와 위험 범위 | 반격 신호와 시간 |
| --- | --- | --- |
| **집게 내려찍기** | 빠른 옆걸음으로 접근 → 멈추며 공격 방향 고정 → 플레이어 쪽 집게를 높이 들고 **0.64초** 유지 → 현재 바라보는 쪽 앞바닥에 수직 타격. 플레이어를 따라 새로 방향을 틀지 않는다. | 타격이 끝나 아래 집게가 바닥에 머무를 때, 집게 끝에 기본 베기가 닿는다. 반격 시간은 **0.85초**로 시작한다. 2페이즈 전환 때만 타격 후 곧바로 얼굴과 집게를 접는다. [접근·내려찍기 시안](../assets/concepts/b1-hermit-crab/claw-approach-slam-preview-v1.gif) |
| **단발 점프 낙하** | 다리를 접고 발구름 → 화면 밖 **1.4초** 대기 → 그 순간의 플레이어 위치를 기준으로 낙하 지점 고정 → 바닥 그림자와 자갈로 **0.8초** 예고 → 같은 지점에 수직 낙하. 그림자 폭을 실제 착지 피해 폭에 맞춘다. | 착지 피해가 끝나 등딱지와 집게가 한 박자 더 내려앉고 잠시 멈춘다. 낮아진 얼굴이나 앞집게에 **1.10초** 동안 반격할 수 있다. [점프·착지 시안](../assets/concepts/b1-hermit-crab/boss-jump-preview-v4.gif) |
| **2연속 점프 낙하** | 각 낙하에 같은 발구름과 **1.4초 대기·0.8초 예고**를 쓴다. 첫 착지에서는 몸을 누른 채 멈추는 자세를 건너뛰고 다리를 바로 굽혀 다시 발구름한다. 두 번째 낙하 위치는 두 번째 예고 직전에 새로 고정한다. | 첫 착지에서는 다리를 다시 굽히는 동작을 보고 다음 회피를 준비한다. 두 번째 착지에서 몸이 내려앉아 멈추면 **1.25초** 동안 반격할 수 있다. |
| **암석으로 은신 해제** | 집게와 다리를 접어 등딱지가 바닥에 닿으면 레일 장착부와 중앙 암석의 균열이 드러난다. 안쪽 발판에서 암석을 타격하면 등딱지로 떨어져 부서진다. | 암석은 등딱지 방어를 푼다. 플레이어가 바닥에 돌아오면 소라게가 낮춘 얼굴을 **1.20초** 드러낸 뒤 첫 집게의 접근을 시작한다. [천장 암석과 발판 배치](../assets/concepts/b1-hermit-crab/ceiling-rock-v2/room-placement-preview.png) |

## 은신 중 이동과 재도전

- **유물 레일**은 하단 A에서 익힌 입력 흐름을 사용한다. `E`로 장착하고 `X`로 레일 파츠를 보낸 뒤 상단에 정차하면 `E`로 이동한다. 바깥 긴 발판을 거쳐 안쪽 짧은 발판에서 균열 난 암석에 닿는다. 상단 실패 시 바닥으로 내려가 파츠를 회수하고 다시 시도할 수 있게 한다. [상단 배치](../assets/concepts/b1-hermit-crab/ceiling-rock-v2/room-placement-preview.png) · [기존 조작](../README.md)
- **암석과 등딱지**는 단계별로 상태를 관리한다. 도입의 낙석과 은신 해제용 암석을 다른 물체로 처리해, 포효 뒤에도 상단에 균열 암석이 남아 있게 한다. 은신 중에는 보스 공격과 접촉 피해를 끄고 퍼즐 시간을 제한하지 않는다. 암석 타격과 방어 해제는 각 전투에서 한 번만 인정한다.
- **바닥 복귀**는 안쪽 발판에서 등딱지 옆 빈 바닥으로 내려오는 동선을 쓴다. 플레이어가 안정적으로 착지하기 전까지 소라게는 대기한다. 레일 구간에서 유물을 다시 회수할 수 있고, 석문이 닫힌 동안 `E`·`Q`의 목적지는 방 안으로 제한한다.
- **사망 후 재도전**은 C 전실의 활성화된 석등으로 돌아간다. 획득한 유물은 유지하고, 보스 체력과 페이즈, 석문, 레일, 두 암석, 전투 중에 남긴 유물 위치와 귀환 지점을 초기화한다. [C 전실과 B1 진입](INITIAL_DESIGN.md#62-맵-1-이끼-낀-지하-동굴--발견과-기본기)

## 첫 플레이테스트

- **도입 입력.** 입장만 한 경우, 조사 범위를 스쳐 지나가는 경우, 범위 밖 `E`, 유물을 보유한 채 조사, 조사 키를 연달아 누르는 경우를 비교한다. 유효한 조사에서만 진동과 포효가 한 번씩 재생되고, 조작을 되찾은 뒤 첫 집게 전조가 보이는지 확인한다.
- **회피 동선**은 집게의 좌우 방향과 낙하의 방 중앙·양 끝을 확인한다. 유물 없이도 그림자를 본 뒤 기본 이동으로 빠져나갈 수 있게 피해 폭을 잡고, 발판과 벽이 전조나 퇴로를 가리지 않는지 본다.
- **반격 시간**은 집게 끝과 낮아진 얼굴의 베기 판정을 점검한다. 공격이 끝난 뒤 이동해 기본 베기 한 번이 닿는지, 2연속의 첫 착지와 마지막 착지를 자세만으로 구별할 수 있는지 확인한다. 첫 착지에 맞아도 다음 낙하의 예고 시간 안에 이동을 시작할 수 있어야 한다.
- **페이즈 전환**은 체력 50%를 넘기는 강한 공격, 공격 중 전환 예약, 암석 연타, 상단에서 떨어진 뒤 재시도, 보스전 중 사망과 재입장을 재현한다. 암석 충돌 뒤 바닥으로 복귀할 때의 첫 반격도 확인한다.

영혼 통달자에게서 연속 낙하 뒤에 반격이 열리는 흐름을, 사마귀 군주들에게서 한 번 배운 전조를 반복해 대응을 바꾸는 구성을 참고했다. 거짓된 기사처럼 보스의 자세 변화로 공격 기회를 보여 주고, 소라게의 은신에서는 레일과 천장 암석으로 전투를 다시 연다. [할로우 나이트 공격 패턴 조사](hollow-knight-combat-pattern-study.md)
