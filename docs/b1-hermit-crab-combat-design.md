# B1 바위 소라게 전투 설계

맵 1의 첫 보스전이다. 첫 교전에서 집게 내려찍기와 점프 낙하의 전조와 반격을 익힌다. 소라게가 등딱지에 숨으면 유물 레일로 상단에 올라가 천장 암석을 떨어뜨린다. 다시 깨어난 뒤에는 같은 낙하를 두 번 연결해 안전한 반격 시점을 판단하게 한다. 체력 기준, 연계 순서, 새로 정한 시간은 첫 플레이테스트 가안이다.

## 보스 AI 상태표

보스는 현재 상태의 행동을 수행하고, 전환 조건이 충족되면 다음 상태로 간다. 새 공격은 이전 공격의 회복이 끝날 때 고른다.

| 상태 | 보스 행동 | 다음 상태로 가는 조건 |
| --- | --- | --- |
| 조사 대기 | 방 중앙에서 등딱지만 드러낸다. | 바닥에서 등딱지 앞에 접근해 `E 조사` → **시작 연출** |
| 시작 연출 | 화면 진동과 낙진 → 별도 도입 암석 충돌로 눈을 뜸 → 입구 석문 닫힘 → 포효. | 포효가 끝나면 조작을 돌려주고 **기본 교전** |
| 기본 교전 | 첫 두 공격은 집게 → 단발 낙하. 이후 집게 사거리 안이면 집게, 그 밖이면 단발 낙하를 쓴다. 같은 공격을 연속 두 번 썼으면 다음에는 다른 공격을 고른다. | 체력 50%에 도달하고 첫 두 공격과 마지막 회복을 마침 → **은신** |
| 은신 | 중앙에서 제자리 집게를 한 번 내려찍고 등딱지에 숨는다. 유물 레일을 켠다. | 상단에서 떨어뜨린 천장 암석이 등딱지에 닿음 → **재등장** |
| 재등장 | 몸을 펴고 기다린다. 플레이어가 전투 바닥에 착지하면 얼굴을 **1.20초** 드러낸다. | 반격 시간이 끝남 → **2페이즈** |
| 2페이즈 | 2연속 낙하 → 집게 → 단발 낙하 → 집게를 반복한다. | 체력 0 → **격파** |
| 격파 | 남은 공격을 끄고 C 전실로 돌아가는 보스방의 오른쪽 석문을 연다. 4초 격파 시퀀스와 맵 2 장벽 해제는 별도 계획에 따른다. [격파 연출과 다리 장벽 해제 계획](#격파-연출과-다리-장벽-해제-계획) | 재입장해도 격파 상태를 유지한다. |

- 조사 범위 안의 `E`는 조사에 한 번만 쓴다. 범위 밖에서는 기존 조작을 적용한다. 시작 연출 중에는 이동·공격·유물 입력과 피해 판정을 잠시 끈다.
- 집게의 방향과 낙하 지점은 전조가 시작되면 고정한다. 체력 50%에 도달해도 이미 시작한 공격과 회복은 끝까지 실행한다. 은신 해제 전까지 체력 하한은 50%다.
- 보스 체력이 0이 되면 현재 공격이나 반격 시간을 종료하고 **격파**로 간다. 플레이어가 사망하면 연출·판정·타이머를 정리하고 C 전실 석등으로 돌아간다. 새 시도는 **조사 대기**부터 시작한다. 같은 프레임에 두 조건이 겹치면 재도전을 우선하는 가안이다.

## 도입 연출 타이밍

| 조사 뒤 시간 | 화면과 보스 | 다음 행동 조건 |
| --- | --- | --- |
| 입력 전 | 오른쪽 통로에서 중앙 등딱지까지 접근한다. 바닥의 조사 범위에서 `E 조사`를 띄운다. 방에 들어오는 것만으로는 등딱지가 움직이지 않는다. | 범위 안에서 새 `E` 입력 |
| 0.00–3.20초 | 조사 문구를 지운다. 처음 약 0.60초 동안 천장과 보스가 보이도록 시야를 넓힌다. 진동은 0.00·0.46·0.94·1.43·1.90초에 시작한다. 마지막 구간에 도입 암석이 등딱지에 닿아 눈을 뜨고, 플레이어가 조사 위치에 있는 동안 오른쪽 입구 석문이 닫힌다. | 충돌과 입구 석문 닫힘 연출 완료 |
| 약 3.20–5.20초 | 소라게가 몸을 낮췄다가 고개와 집게를 들어 포효한다. 포효 자체의 0.72–1.13초가 정점이며 공기 파동과 바닥 돌먼지가 퍼진다. 도입 암석과 포효는 연출로 처리한다. | 포효 종료와 전투 자세 복귀 |
| 약 5.20초 | 플레이어 조작을 복구하고 첫 집게 접근을 시작한다. 집게는 공격 방향을 고정하고 0.64초 전조를 거친 뒤 타격한다. | 1페이즈 첫 공격 실행 |

조사·진동은 기존 3.20초 시안, 포효는 기존 2초 애니메이션을 기준으로 잡았다. 진동은 카메라에만 적용해 지형과 충돌 좌표를 고정한다. 도입 암석은 은신 해제용 중앙 천장 암석과 별개이며, 중앙 암석은 은신 해제에 사용하기 전까지 매달려 있다. [조사·진동 시안](../tools/preview_b1_intro.py) · [포효 자세와 타이밍](../assets/concepts/b1-hermit-crab/roar-v4/README.md)

## 공격 전조와 반격

집게는 **접근 → 방향 고정 → 전조 → 타격 → 회복** 순서로 실행한다. 낙하는 **발구름 → 화면 밖 대기 → 목표 고정 → 예고 → 착지**의 같은 동작을 단발은 한 번, 2연속은 두 번 실행한 뒤 회복한다. 두 번째 낙하의 목표는 두 번째 예고가 시작될 때 다시 잡는다.

반격 시간은 공격의 피해 판정이 끝난 뒤부터 잰다. 전조를 보고 기본 이동으로 타격을 피한 자리에서, 반격 시간 안에 다가가 기본 베기 한 번을 넣을 수 있어야 한다. 다음 공격의 피해는 새 전조를 거친 뒤에 발생한다.

| 공격 | 전조와 위험 범위 | 반격 신호와 시간 |
| --- | --- | --- |
| **집게 내려찍기** | 빠른 옆걸음으로 접근 → 멈추며 공격 방향 고정 → 플레이어 쪽 집게를 높이 들고 **0.64초** 유지 → 현재 바라보는 쪽 앞바닥에 수직 타격. 플레이어를 따라 새로 방향을 틀지 않는다. | 타격이 끝나 아래 집게가 바닥에 머무를 때, 집게 끝에 기본 베기가 닿는다. 반격 시간은 **0.85초**로 시작한다. 은신 직전의 중앙 집게 뒤에는 얼굴과 집게를 접는다. [접근·내려찍기 시안](../assets/concepts/b1-hermit-crab/claw-approach-slam-preview-v1.gif) |
| **단발 점프 낙하** | 다리를 접고 발구름 → 화면 밖 **1.4초** 대기 → 그 순간의 플레이어 위치를 기준으로 낙하 지점 고정 → 바닥 그림자와 자갈로 **0.8초** 예고 → 같은 지점에 수직 낙하. 그림자 폭을 실제 착지 피해 폭에 맞춘다. | 착지 피해가 끝나 등딱지와 집게가 한 박자 더 내려앉고 잠시 멈춘다. 낮아진 얼굴이나 앞집게에 **1.10초** 동안 반격할 수 있다. [점프·착지 시안](../assets/concepts/b1-hermit-crab/boss-jump-preview-v4.gif) |
| **2연속 점프 낙하** | 각 낙하에 같은 발구름과 **1.4초 대기·0.8초 예고**를 쓴다. 첫 착지에서는 몸을 누른 채 멈추는 자세를 건너뛰고 다리를 바로 굽혀 다시 발구름한다. 두 번째 낙하 위치는 두 번째 예고 직전에 새로 고정한다. | 첫 착지에서는 다리를 다시 굽히는 동작을 보고 다음 회피를 준비한다. 두 번째 착지에서 몸이 내려앉아 멈추면 **1.25초** 동안 반격할 수 있다. |
| **암석으로 은신 해제** | 집게와 다리를 접어 등딱지가 바닥에 닿으면 레일 장착부와 중앙 암석의 균열이 드러난다. 안쪽 발판에서 암석을 타격하면 등딱지로 떨어져 부서진다. | 암석은 등딱지 방어를 푼다. 플레이어가 바닥에 돌아오면 소라게가 낮춘 얼굴을 **1.20초** 드러낸 뒤 2연속 낙하를 시작한다. [천장 암석과 발판 배치](../assets/concepts/b1-hermit-crab/ceiling-rock-v2/room-placement-preview.png) |

## 은신 중 이동과 재도전

- **은신 전환.** 체력 50%에 도달하는 타격은 정상 명중으로 처리한다. 이후 등딱지 표면에 방어 피드백을 주고, 회복 뒤 중앙으로 이동한다. 중앙 집게는 그 자리에서 한 번 타격하고 바로 몸을 접는다.
- **유물 레일**은 하단 A에서 익힌 입력 흐름을 사용한다. `E`로 장착하고 `X`로 레일 파츠를 보낸 뒤 상단에 정차하면 `E`로 이동한다. 바깥 긴 발판을 거쳐 안쪽 짧은 발판에서 균열 난 암석에 닿는다. 상단 실패 시 바닥으로 내려가 파츠를 회수하고 다시 시도할 수 있게 한다. [상단 배치](../assets/concepts/b1-hermit-crab/ceiling-rock-v2/room-placement-preview.png) · [기존 조작](../README.md)
- **암석과 등딱지**는 단계별로 상태를 관리한다. 도입의 낙석과 은신 해제용 암석을 다른 물체로 처리해, 포효 뒤에도 상단에 균열 암석이 남아 있게 한다. 은신 중에는 보스 공격과 접촉 피해를 끄고 퍼즐 시간을 제한하지 않는다. 암석 타격과 방어 해제는 각 전투에서 한 번만 인정한다.
- **바닥 복귀**는 안쪽 발판에서 등딱지 옆 빈 바닥으로 내려오는 동선을 쓴다. 플레이어가 안정적으로 착지하기 전까지 소라게는 대기한다. 레일 구간에서 유물을 다시 회수할 수 있고, 석문이 닫힌 동안 `E`·`Q`의 목적지는 방 안으로 제한한다.
- **사망 후 재도전**은 C 전실의 활성화된 석등으로 돌아간다. 획득한 유물은 유지하고, 보스 체력과 페이즈, 석문, 레일, 두 암석, 전투 중에 남긴 유물 위치와 귀환 지점을 초기화한다. [C 전실과 B1 진입](INITIAL_DESIGN.md#62-맵-1-이끼-낀-지하-동굴--발견과-기본기)

## 격파 연출과 다리 장벽 해제 계획

막타로 소라게가 떨리기 시작하고, 등딱지에서 새어 나온 에너지가 한 번 안으로 모였다가 폭발한다. 빛이 걷히면 바닥에 무너진 소라게가 드러나고, 마지막 푸른 불씨가 오른쪽으로 날아가 맵 2로 가는 다리의 장벽을 해제한다. 약 4초의 연출에 막타 히트스톱과 폭발 직전 정적을 포함한다.

### 막타부터 도깨비불 이탈까지

| 막타 뒤 시간 | 보스와 공간 | 카메라와 소리 |
| --- | --- | --- |
| 0.00–0.15초 | 체력이 0이 되는 마지막 타격에만 **0.15초 히트스톱**을 건다. 마지막 타격 자세에서 플레이어와 보스 동작을 잠깐 멈춘다. | 카메라는 직전 구도를 잡고, 타격음은 한 번 난다. |
| 0.15–0.55초 | 몸이 떨리고 집게가 무게를 못 이겨 바닥에 닿는다. 닿은 지점에서 돌먼지가 짧고 낮게 번진다. | 집게 접지에 둔탁한 석재 충돌음을 맞춘다. 화면 진동이 약하게 시작된다. |
| 0.55–1.45초 | 눈과 등딱지 틈에서 가느다란 푸른 줄기가 새어 나온다. 새는 양과 몸의 떨림이 커진다. | 카메라 진동과 낮게 깔리는 울림의 강도를 올린다. |
| 1.45–1.60초 | 새어 나오던 에너지가 등딱지 안쪽 한 점으로 되감기듯 모인다. | **0.15초 정적**을 둔다. 카메라 진동과 연출음을 즉시 끊고 주변음도 낮춘다. |
| 1.60–1.90초 | 보스 몸 안에서 터진 빛이 방으로 확산된다. 바닥 충격파와 먼지가 양쪽으로 달리고, 천장에서 작은 돌과 먼지가 떨어진다. 빛이 가장 밝을 때 보스가 바닥으로 무너진다. | 보스 위치를 중심으로 처음 밝아지고, 짧은 백색 정점이 한 번 온다. 폭발음과 짧은 진동을 맞춘 뒤 카메라를 안정시킨다. |
| 1.90–2.50초 | 원래 조명으로 서서히 돌아오며 힘없이 내려앉은 소라게가 드러난다. 공중 먼지는 가라앉고 일부 파편만 바닥에 남는다. | 폭발음의 낮은 잔향과 함께 방의 평상시 분위기를 회복한다. |
| 2.50–4.00초 | 등딱지 틈에서 푸른 도깨비불 하나가 생겨 떠오른다. 잠깐 머물며 불꽃 끝을 오른쪽으로 틀고, 가속해 화면 밖으로 나간다. | 맑은 여운에 가는 바람 소리를 섞은 전용음을 쓴다. 소리는 출현 때 울리고 오른쪽으로 멀어지며 작아진다. 카메라는 보스방 구도를 유지한다. 이탈이 끝나면 조작을 돌려준다. |

### 폭발이 방에 미치는 반응

- 빛은 격파 위치에 월드 좌표로 고정한다. 보스 가까운 바닥과 표면이 먼저 밝아지고, 영향 범위가 넓어지면서 약해진다. 현재 합성 순서를 이용해 원경에는 옅은 밝기, 중경 아치에는 조금 강한 반사광, 가까운 지형과 집게 주변에는 가장 강한 빛을 준다. 전경은 윤곽에만 짧게 빛을 받아 가림 관계가 유지된다. 백색 정점은 이 변화 위에 짧게 겹친다. [B1 방 레이어](../tools/b1_room_art.py) · [맵 시각 가이드](../MAP_VISUAL_GUIDE.md)
- 기존 바닥 먼지와 천장 낙진 효과를 격파에 맞춰 조정한다. 바닥 충격파는 보스 발밑에서 수평으로 퍼지고, 천장 자갈은 한 박자 뒤 떨어진다. 밝기와 입자 발생량은 점차 줄인다. 충격파와 떨어지는 장식 조각은 피해나 이동 판정을 만들지 않는다. [카메라와 먼지 효과](../tools/b1_encounter_stage.py)
- 막타 정지 시간, 떨림 구간과 진동 최대치, 정적 길이, 빛의 확산 반경과 레이어별 밝기, 백색 정점과 감쇠 시간, 입자 수와 수명, 사운드 음량은 각각 조절할 수 있게 계획한다. 첫 검수는 정점 약 0.10초와 원경·중경·지형의 상대 강도 0.2·0.55·1.0에서 시작한다. 전경은 윤곽에만 약하게 적용한다.
- 응축, 청백색 폭발과 잔광을 투명 WebP로 제작하고 B1 보스방 미리보기에서 그 위에 짧은 백색 섬광을 합성했다. [섬광 독립 레이어와 보스방 미리보기](../assets/concepts/b1-hermit-crab/defeat-v1/README.md#섬광-독립-레이어)

### 격파된 소라게와 도깨비불

- **격파 자세**는 전용 이미지 제작 또는 기존 자세 보완으로 준비한다. 바닥에 기운 몸, 한쪽이 파손된 등딱지, 꺼진 눈과 발광 문양, 힘없이 풀린 집게를 한눈에 읽히게 한다. 격파 위치와 방향, 바닥에 남길 소수 파편의 배치를 현재 플레이에 저장한다. 재입장 시 같은 모습으로 놓고 반격·접촉 피해·통행 차단 없이 지나갈 수 있게 한다.
- 점멸 직전과 직후 자세는 각각 독립 PNG로 만들었다. 두 자세의 바닥을 맞추고 흰빛이 가장 밝을 때 전환하는 4초 미리보기를 제작했다. [두 자세와 애니메이션](../assets/concepts/b1-hermit-crab/defeat-v1/README.md)
- **도깨비불**은 청백색의 밝은 심과 푸른 외곽 불꽃을 가진 독립 스프라이트로 구상한다. 외곽은 늘고 접히며, 오른쪽으로 나갈 때 뒤로 길어진다. 약 2.50초 생성, 2.68초 상승, 2.98초 체류, 3.16초 방향 전환, 3.28초 가속, 3.84–4.00초 화면 이탈을 기준으로 동작을 구분한다. 비행 중에만 짧은 발광 꼬리와 작은 잔광을 남기고, 근처 바닥과 유적에 약한 푸른빛을 비춘다. 각 동작의 길이·경로·속도, 꼬리의 길이·수명, 반사광의 범위와 강도는 별도로 조정한다.

### 길이 열리는 시점과 상태 유지

- 도깨비불이 오른쪽으로 날아간 뒤 남은 잔광이 보스방의 오른쪽 출구 쪽으로 시선을 안내한다. 보스방 오른쪽 석문은 C 전실 복귀로 이어진다. 맵 2로 가는 장벽은 **A 착지대 오른쪽의 별도 다리 구역**에 있다. [맵 1 오른쪽 다리 계획](map1-right-sealed-passage-draft.md#푸른-장벽과-맵-2-연결-계획)
- 도깨비불이 다리 장벽에 닿으면 푸른 에너지가 중심으로 말려 들어갔다가 사라진다. 카메라는 보스방에서 연출을 마친다. 격파 후 플레이어가 다리에 처음 돌아온 시점에 장벽 주변에서 도깨비불과 같은 색의 잔광을 보여 주고 서서히 걷는다. 잔광이 남아 있는 동안에도 다리를 건널 수 있다.
- 체력이 0이 되는 순간 **격파 연출 중** 상태에 한 번만 들어간다. 즉시 새 공격과 남은 피해 판정·전조를 끈다. 히트스톱은 동작에만 걸고, 화면 갱신과 입력 이벤트 처리는 계속한다. 격파 연출 중에는 전투 조작과 유물 시점을 잠시 제한하고, 이전에 누른 공격·유물 입력이 종료 뒤 밀려 나오지 않도록 정리한다.
- 도깨비불의 화면 이탈에서 **격파 완료**와 다리 장벽 해제를 함께 확정하고, 진동·연출음·광원·입력 잠금을 정리한 뒤 기존 오른쪽 석문 개방에 연결한다. 현재 플레이의 `b1_cleared`를 공유하며, 보스방 재입장은 사체와 파편을 복원하고 다리 재입장은 이미 해제된 상태를 유지한다. 기존 `R` 전체 재시작은 격파·장벽·잔광 표시 기록을 함께 초기화한다. 플레이어와 보스가 같은 프레임에 쓰러지는 경우 기존 재도전 우선순위를 사용한다. [행동트리](../tools/b1_combat_tree.py) · [본편 상태 연결](../main.py)

### 제작 순서와 실제 화면 검증

1. **기존 구조에 맞춰 타이밍을 검증한다.** 현재 코드의 체력 0 분기, 방의 배경·지형·전경 렌더링, 카메라 진동과 먼지, 본편 격파 기록을 우선 활용한다. 저장소에는 동굴 앰비언스 WAV가 있고 본편의 효과음 재생 경로는 확인되지 않았다. 집게 충돌음, 고조와 정적, 폭발음, 도깨비불 전용음을 시점별로 연결할 최소 재생 경로를 제작 단계에서 정한다.
2. **독립 보스 테스트에서 화면과 소리를 맞춘다.** 방 중앙과 양 끝, 양쪽 방향에서 막타를 넣어 집게 접지와 사운드, 0.15초 정적, 보스 중심 확산광, 백색 정점과 쓰러진 자세의 전환을 확인한다. HUD와 인물의 판독성, 도깨비불의 오른쪽 방향, 벽과 바닥의 반사광을 실제 화면에서 확인한다. 30·60·144fps에 해당하는 프레임 간격으로 재생해 두 0.15초 구간을 포함한 총길이가 약 4초이고 충돌음·폭발·도깨비불이 각 한 번 재생되는지 확인한다. [독립 테스트 실행](../play-b1-encounter.cmd)
3. **본편에서 상태와 동선을 확인한다.** 연출 중 입력 연타, 막타 직전 진행 중이던 공격, 조작 복구, 사망 우선, 방 재입장, `R` 초기화를 재현한다. 첫 다리 방문에서 장벽의 밀어내기와 일반 이동·유물 우회 차단을 확인하고, 격파 뒤 첫 복귀에서 잔광과 통과를 확인한다. 이후 여러 번 방을 오가도 사체·파편·열린 장벽이 유지되고 격파 연출이나 잔광이 중복 재생되지 않아야 한다.

## 본편 진행과 재도전

1. 하단 B에서 C 전실까지 이동해 바닥의 석등에 접근한다. 석등이 켜지면 왼쪽 봉인문이 열리고, 바닥에서 왼쪽으로 계속 걸어 B1 통로에 들어간다.
2. 오른쪽 통로에서 중앙 등딱지까지 걸어가 `E`로 조사한다. `E`는 등딱지 조사와 레일 조작을 우선 처리하며, 평소에는 유물을 설치하거나 그 위치로 순간이동한다. 유물로 순간이동하거나 레일을 타고 올라간 뒤 3초 동안 `Q`로 출발 지점의 흔적에 한 번 돌아갈 수 있다. `C`를 누르는 동안 유물 위치를 확인할 수 있다.
3. 쓰러지면 암전이 끝난 뒤 C 석등에서 체력을 회복한다. 유물은 소지한 채로 돌아오며, 다시 입장하면 보스 조사부터 시작한다. `R`은 현재 실행 모드의 시작 위치로 돌아간다.
4. 소라게를 격파하면 오른쪽 석문이 열린다. 통로 끝까지 오른쪽으로 걸으면 C 전실로 돌아간다. 같은 플레이에서 다시 들어와도 격파 상태를 유지한다. [맵 2로 가는 다리 계획](map1-right-sealed-passage-draft.md#푸른-장벽과-맵-2-연결-계획)

## 기본 교전 조작 테스트

프로젝트 폴더에서 `play-b1-encounter.cmd`를 실행한다. 오른쪽 통로에서 `A/D` 또는 방향키로 움직이고, `Shift`로 달리고 `Space`로 점프한다. 등딱지 앞에 **E 조사**가 보이면 `E`로 시작한다. `R`로 입구에서 다시 시작하고 `Esc`로 닫는다.

진동·낙석·포효 뒤 기본 교전이 시작된다. 집게는 든 자세를 0.64초 유지하고 타격 후 0.85초 회복한다. 낙하는 화면 밖에서 1.4초 기다린 뒤 그 순간의 플레이어 위치에 바닥 표식을 고정한다. 0.8초 예고가 끝난 뒤 낙하한다. 단발 낙하는 착지 후 1.10초, 2연속 낙하는 두 번째 착지 후 1.25초 동안 반격할 수 있다. 표시 범위에서 공격에 맞으면 타격당 테스트용 피해 25를 받는다.

보스의 최대 체력은 96이며 화면에 표시하지 않는다. 공격 회복 중 집게 끝이나 낮아진 몸에 `X` 베기를 맞히면 기본 공격력 12만큼 줄어든다. 체력 50%에서 은신과 천장 바위 기믹을 거친 뒤 2페이즈로 넘어간다. 독립 테스트에서 플레이어가 쓰러지면 교전을 멈추고 `R`로 재도전한다.

### 기본 교전 행동트리

```text
우선순위 선택기
├─ 플레이어 사망 → 교전 정지
├─ 보스 체력 0 → 격파
├─ 진행 중인 공격 있음 → 회복이 끝날 때까지 계속 실행
├─ 은신 기믹 진행 중 → 암석 충돌 → 바닥 복귀 → 얼굴 노출 → 2페이즈 진입
├─ 체력 50%이고 첫 두 공격 완료 → 중앙으로 이동 → 집게 1회 → 숨기
├─ 2페이즈 → 2연속 낙하 → 집게 → 단발 낙하 → 집게를 반복
└─ 1페이즈의 새 공격 선택
   ├─ 도입 직후 두 공격 → 집게, 단발 낙하 순서
   ├─ 직전 공격을 두 번 연속 사용 → 다른 공격
   ├─ 플레이어가 집게 사거리 안 → 집게
   └─ 그 밖 → 단발 점프 낙하
```

[행동트리 코드](../tools/b1_combat_tree.py)가 이 순서로 조건을 평가한다. 실패한 조건은 다음 가지로 넘어간다. 2연속 낙하는 하나의 공격으로 다룬다. 첫 착지 직후 다시 뛰어 두 번째 예고에서 플레이어 위치를 새로 고정한다. 두 번째 착지의 회복까지 끝나면 다음 공격으로 넘어간다. 1페이즈에서 집게를 고르는 기준은 가로 거리 628 월드 단위와 높이 232 월드 단위다. 낙하의 타격 너비는 방 가장자리에서 잘린 바닥 표식과 일치한다.

### 50% 은신 구간 조작

1. 보스가 중앙 집게를 마치고 숨으면 어느 쪽 레일이든 바닥 장착부에 접근한다. `E`로 유물을 장착하고, 레일 파츠를 향해 `X`로 베어 올린다. 상단에 도착한 뒤 바닥에서 `E`로 큰 발판에 이동한다.
2. 안쪽을 향해 달려 `Shift+Space`로 짧은 발판에 건너간다. 꼭대기의 균열 바위를 향해 `X`로 베면 바위가 등딱지 위로 떨어져 부서진다.
3. 소라게가 다시 나오면 전투 바닥으로 내려간다. 바닥에 착지하면 1.20초 동안 반격할 수 있다. 2페이즈가 시작되면 각 낙하의 바닥 표식을 보고 두 번 피한 뒤 반격한다.

아래 명령은 도입부터 기본 공격까지 SDL 정지 화면을 저장한다.

```powershell
.\play-b1-encounter.cmd --stills .cache/b1-adaptive-ai
```

## 첫 플레이테스트

- **도입 입력.** 입장만 한 경우, 조사 범위를 스쳐 지나가는 경우, 범위 밖 `E`, 유물을 보유한 채 조사, 조사 키를 연달아 누르는 경우를 비교한다. 유효한 조사에서만 진동과 포효가 한 번씩 재생되고, 조작을 되찾은 뒤 첫 집게 전조가 보이는지 확인한다.
- **회피 동선**은 집게의 좌우 방향과 낙하의 방 중앙·양 끝을 확인한다. 유물 없이도 그림자를 본 뒤 기본 이동으로 빠져나갈 수 있게 피해 폭을 잡고, 발판과 벽이 전조나 퇴로를 가리지 않는지 본다.
- **반격 시간**은 집게 끝과 낮아진 얼굴의 베기 판정을 점검한다. 공격이 끝난 뒤 이동해 기본 베기 한 번이 닿는지, 2연속의 첫 착지와 마지막 착지를 자세만으로 구별할 수 있는지 확인한다. 첫 착지에 맞아도 다음 낙하의 예고 시간 안에 이동을 시작할 수 있어야 한다.
- **페이즈 전환**은 체력 50%를 넘기는 강한 공격, 공격 중 전환 예약, 암석 연타, 상단에서 떨어진 뒤 재시도, 보스전 중 사망과 재입장을 재현한다. 암석 충돌 뒤 바닥으로 복귀할 때의 첫 반격도 확인한다.

영혼 통달자에게서 연속 낙하 뒤에 반격이 열리는 흐름을, 사마귀 군주들에게서 한 번 배운 전조를 반복해 대응을 바꾸는 구성을 참고했다. 거짓된 기사처럼 보스의 자세 변화로 공격 기회를 보여 주고, 소라게의 은신에서는 레일과 천장 암석으로 전투를 다시 연다. [할로우 나이트 공격 패턴 조사](hollow-knight-combat-pattern-study.md)
