# 하단 B파트 · 가시 협곡과 공중 전투 발판

A의 왼쪽 발판은 같은 높이의 이끼 돌길로 B 오른쪽 출발대까지 이어진다. 발판 사이는 위아래 가시벽 사이로 솟는 레일, 벽점프, 돌바닥 아래로 내려가는 레일 순서로 건너 왼쪽 C 연결부에 닿는다. [개편 전 콘셉트 도면](map1-lower-route-b-blockout-v2.png)

## 맵 미술

연결부 양쪽의 바닥과 원경을 겹쳐 그려 한 동굴처럼 이어지게 했다. 이동 카메라의 세로 구도는 돌길을 따라 점진적으로 바뀐다. 두 구간을 오갈 때 설치한 유물이나 레일 상태도 이어진다. [본편 연결부](map1-lower-route-ab-connection.png) · [연결 원화](../assets/terrain/lower-route-ab-passage-v1.png) · [내장 image_gen 프롬프트](../assets/terrain/lower-route-ab-passage-v1.prompt.txt)

원경은 A파트와 같은 청록빛 동굴에 폐수로·육각 문양 기둥·큰 석륜·멀리 흐르는 물줄기를 배치한다. 벽점프 슬롯은 천장에서 내려온 바위와 방패병 발판 밑의 돌출암으로 둘러싼다. 두 벽의 접촉면은 도면에 맞추고, 바깥쪽 암반과 장식은 불규칙하게 다듬는다.

발판은 젖은 청회색 돌과 이끼 군집을 공통으로 쓴다. C 전실의 새 원화는 B 왼쪽 발판과 같은 높이에 놓고, 연결부에서 B 원경과 돌길에 점차 섞어 그린다. 방패병 발판의 오른쪽은 벽점프 벽으로 이어지고, 공벌레 발판의 석조 받침은 가시 사이까지 내려간다.

첫 레일의 바닥과 천장, 두 번째 레일의 중앙에 [세로 가시벽](../assets/structures/map1-lower-route/lower-cave-thorn-wall-v1.png)을 배치한다. 기존 가시바닥의 위치에 돌바닥을 놓고 아래를 암반으로 채웠다. 두 번째 레일의 하강·상승 통로를 사이에 두고 돌바닥이 끊긴다.

원경은 내장 image_gen으로 제작했다. 본편에서 A 왼쪽 출구를 지나 B 전 구간과 C 전실까지 걸어서 이동할 수 있다. 본편과 미리보기는 `lower_route_b_art.py`로 같은 발판과 가시를 그린다. B 전체 시안은 `.\.venv\Scripts\python.exe -m tools.preview_lower_route_b`로 렌더링한다.

## 진행 순서

| 순서 | 이동과 전투 |
| --- | --- |
| A 연결과 첫 레일 출발대 | 가까운 파츠에 `E`로 유물을 장착하고 왼쪽을 보며 `X`로 친다. 파츠가 높이 올라 첫 두 가시벽의 끝 사이를 통과한 뒤 공벌레 발판 쪽으로 내려온다. 건너편에 정차하면 `E`로 이동한다. |
| 공벌레 발판 | 오른쪽 끝 여유 구간에서 착지한다. 안쪽 공벌레를 지나 왼편으로 들어가면 벽 사이에 도약할 공간이 나온다. |
| 벽점프 상승 | 아래 발판에서 왼쪽 벽으로 도약한다. 오른쪽 벽을 거쳐 다시 왼쪽으로 튕기면 위 발판에 닿는다. 두 발판의 높이차는 410이고 벽 사이 폭은 250이다. 오른쪽 벽 아래는 걸어서 진입할 수 있고, 위쪽은 천장과 이어진다. |
| 방패병 발판 | 발판 오른쪽에서 착지하고 가운데 방패병을 만난다. 발판이 넓어 뒤로 물러서거나 뒤로 돌아갈 수 있다. 왼쪽 끝에 두 번째 레일 출발대를 둔다. |
| 두 번째 레일과 C 접근 발판 | 파츠가 방패병 발판에서 출발해 돌바닥 아래를 통과한 뒤 C 접근 발판 위에 정차한다. `C`를 눌러 도착을 확인하고 `E`로 이동한다. |

B의 공벌레와 방패병은 착지 여유 구역을 벗어나 자기 발판에 접근하면 활성화한다. 방패병의 체력은 65다. 방패 쪽에서 들어오는 베기는 방패를 휘두르는 중에도 막는다. 플레이어가 뒤에 머물면 방패병은 최대 1.5초 동안 기존 방향을 보며, 그 사이 뒤에서 한 대 맞으면 밀리면서 즉시 플레이어 쪽으로 돌아선다.

기존 레일과 같은 직선 파츠와 90도 곡선 파츠를 이어 붙인다. `C`를 누르는 동안 카메라로 이동 중인 유물과 실제 정차 위치를 확인하고 `E`로 이동할 타이밍을 잡는다.

## 비밀 유물방

두 번째 레일의 U자 바닥을 지날 때 `E`로 귀환하면 레일 아래 돌바닥에 내려설 수 있다. 왼쪽으로 들어서면 암반 내부가 드러나고, 통로 끝에서 호박빛 유물에 닿으면 획득한다. 통로 높이는 165로 서 있는 캐릭터보다 25 높다. 오른쪽의 U자 밑으로 돌아와 `E`로 순간이동 유물을 다시 장착하고 왼쪽을 향해 `X`로 치면 C 쪽으로 올라간다. ## 가시 추락과 재시도

가시에 닿으면 체력 25 피해를 받고 가장 최근에 안정적으로 착지한 발판의 안전 구역으로 돌아온다. 레일을 건너는 중이었다면 해당 파츠를 출발 정차점에 돌리고 유물을 플레이어에게 회수한다. 공벌레 발판에서 벽점프에 실패했다면 공벌레 발판에서 다시 도약한다. 추락 전에 처치한 몬스터의 상태는 유지한다. 체력이 0이 되면 B 입구에서 재시작한다. C 석등을 활성화한 뒤에는 C에서 재시작한다.

## C 전실

B 왼쪽 바닥과 같은 높이로 `x=0`에서 이어진다. 진입로 아래는 단단한 암반으로 막혀 있다. 입구 쪽을 순찰하는 공벌레 두 마리를 지나 `x=-710`의 석등에 접근하면 불이 켜지고 재도전 지점이 활성화된다. 석등 너머의 암벽 안쪽에 B1 석조 아치와 봉인문이 있다. `E` 유물 설치와 복귀는 B/C 경계 양쪽에서 이어진다. [C 전실 원화](../assets/terrain/lower-route-c/antechamber-v2-plate.png)

## 배치 치수

오른쪽과 위쪽이 양의 방향이다. 표의 단위는 월드 좌표다.

| 요소 | 배치 |
| --- | --- |
| A 진입 발판 | `x=4460~5000`, 상단 `y=180` |
| 첫 레일 | 출발 `(4620, 280)` → 중앙 최고점 `y=870` → 정차 `(3450, 280)`. 바닥 가시벽 끝은 `y=720`, 천장 가시벽 끝은 `y=1020`. 이동 약 3.3초 |
| 공벌레 발판 | `x=3060~3650`, 상단 `y=180`, 폭 590. 착지 구역 `x=3410~3650` |
| 벽점프 | 왼쪽 면 `x=2900`, 오른쪽 면 `x=3150`. 오른쪽 벽 하단 `y=355` |
| 방패병 발판 | `x=2160~2900`, 상단 `y=590`, 폭 740. 착지 구역 `x=2670~2900`, 레일 출발 구역 `x=2160~2350` |
| 두 번째 레일 | 출발 `(2320, 690)` → 최저점 `y=-560` → 정차 `(1160, 690)`. 이동 약 5.3초 |
| 왼쪽 발판과 C 접근로 | 발판 `x=680~1340`, 상단 `y=590`, 폭 660. 착지 구역 `x=1100~1340`. C 접근로는 `x=0~680` |
| 돌바닥과 비밀 통로 | 돌바닥 상단 `y=-244`, 레일 통로 `x=1408~1616` 및 `x=1842~2050`. 비밀 통로 바닥 `y=-690`, 천장 `y=-525`, 유물 `x=455`. |

현재 플레이어 물리의 평지 달리기 점프 거리는 약 518, 최고 도약 높이는 약 203이다. 본편 입력 테스트에서 첫 레일 중간 하차 후 가시 복귀, 두 레일 횡단, 벽점프, C 연결부 진입을 확인했다. 실제 충돌은 발판과 벽의 주요 석재를 사각형들로 근사한다.

곡선 반경은 96이고 이동 시간은 레일 파츠 속도 660을 기준으로 산정했다. 세그먼트는 왼쪽부터 등록하고, 파츠를 오른쪽 끝에 초기화하면 기존 왼쪽 타격으로 출발한다.
