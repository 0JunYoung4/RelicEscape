# 하단 B파트 · 가시 협곡과 공중 전투 발판

A의 왼쪽 출구에서 B의 오른쪽으로 진입해 왼쪽 C 연결부로 간다. 협곡 하단은 전부 가시로 채운다. 중간의 넓은 공중 발판 세 곳에서 착지하고 전투한다. 발판 사이는 수평 레일, 벽점프, 수평 레일 순서로 건넌다. [B파트 사각형 콘셉트 도면](map1-lower-route-b-blockout-v2.png)

| 순서 | 이동과 전투 |
| --- | --- |
| A 연결과 첫 레일 출발대 | 안전한 발판에서 맞은편 정차점과 착지 구역을 볼 수 있다. 가까운 파츠에 `E`로 유물을 장착하고 왼쪽을 보며 `X`로 친다. 건너편에 정차하면 `E`로 이동한다. |
| 공벌레 발판 | 오른쪽 끝 여유 구간에서 착지한다. 안쪽 공벌레를 지나 왼편으로 들어가면 벽 사이에 도약할 공간이 나온다. |
| 벽점프 상승 | 아래 발판에서 왼쪽 벽으로 도약한다. 오른쪽 벽을 거쳐 다시 왼쪽으로 튕기면 위 발판에 닿는다. 두 발판의 높이차는 410이고 벽 사이 폭은 250이다. 오른쪽 벽 아래는 걸어서 진입할 수 있고, 위쪽은 천장과 이어진다. |
| 방패병 발판 | 발판 오른쪽에서 착지하고 가운데 방패병을 만난다. 발판이 넓어 뒤로 물러서거나 뒤로 돌아갈 수 있다. 왼쪽 끝에 두 번째 레일 출발대를 둔다. |
| 두 번째 레일과 수정 골렘 발판 | 높은 위치에서 가시 협곡을 한 번 더 건넌다. 골렘은 안쪽에 배치해 레일 하차 직후에는 공격받지 않는다. 발판 왼쪽 끝에서 짧은 안전 통로를 거쳐 C로 이어진다. |

몬스터는 착지 여유 구역 밖으로 들어가면 활성화한다. 레일 조작과 벽점프를 하는 동안에는 적의 공격이 건너오지 않도록 발판별 활동 범위를 잡는다. C 연결부는 같은 높이의 통로까지 잡았다.

## 가시 추락과 재시도

가시에 닿으면 기존 테스트룸과 같은 체력 25 피해를 받고 가장 최근에 안정적으로 착지한 발판의 안전 구역으로 돌아온다. 레일을 건너는 중이었다면 해당 파츠를 출발 정차점에 돌리고 유물을 플레이어에게 회수한다. 공벌레 발판에서 벽점프에 실패했다면 공벌레 발판에서 다시 도약한다. 추락 전에 처치한 몬스터의 상태는 유지한다.

## 배치 치수 초안

오른쪽과 위쪽이 양의 방향이다. 표의 단위는 월드 좌표다.

| 요소 | 배치 |
| --- | --- |
| A 진입 발판 | `x=4460~5000`, 상단 `y=180` |
| 첫 레일 | 출발 `(4620, 280)` → 정차 `(3450, 280)`. 발판 사이 폭 810 |
| 공벌레 발판 | `x=3060~3650`, 상단 `y=180`, 폭 590. 착지 구역 `x=3410~3650` |
| 벽점프 | 왼쪽 면 `x=2900`, 오른쪽 면 `x=3150`. 오른쪽 벽 하단 `y=355` |
| 방패병 발판 | `x=2160~2900`, 상단 `y=590`, 폭 740. 착지 구역 `x=2670~2900`, 레일 출발 구역 `x=2160~2350` |
| 두 번째 레일 | 출발 `(2320, 690)` → 정차 `(1160, 690)`. 발판 사이 폭 820 |
| 수정 골렘 발판과 C 연결 | 골렘 발판 `x=680~1340`, 상단 `y=590`, 폭 660. 착지 구역 `x=1100~1340`. C 연결은 `x=0~680` |
| 가시 | `x=0~5000`, 가시 끝 높이 약 `y=-200` |

현재 플레이어 물리의 평지 달리기 점프 거리는 약 518, 최고 도약 높이는 약 203이다. 두 틈과 410 높이차는 일반 점프로 넘을 수 없다. 벽점프 구간은 사각형 충돌과 `Player.update`로 분리해 30·60·120 FPS에서 위 발판 착지를 확인했다. 레일 하차, 적의 활성화 범위, 가시 복귀는 추후 본편 블록아웃에서 확인할 항목이다.
