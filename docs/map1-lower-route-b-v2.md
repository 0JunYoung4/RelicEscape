# 하단 B파트 · 가시 협곡과 공중 전투 발판

A의 왼쪽 발판은 같은 높이의 이끼 돌길로 B 오른쪽 출발대까지 이어진다. 협곡 하단은 전부 가시로 채운다. 중간의 넓은 공중 발판 세 곳에서 착지하고 전투한다. 발판 사이는 위로 솟는 레일, 벽점프, 아래로 돌아 올라오는 레일 순서로 건너 왼쪽 C 연결부에 닿는다. [B파트 사각형 콘셉트 도면](map1-lower-route-b-blockout-v2.png)

## 맵 미술

연결부 양쪽의 바닥과 원경을 겹쳐 그려 한 동굴처럼 이어지게 했다. 이동 카메라의 세로 구도는 돌길을 따라 점진적으로 바뀐다. 두 구간을 오갈 때 설치한 유물이나 레일 상태도 이어진다. [본편 연결부](map1-lower-route-ab-connection.png) · [연결 원화](../assets/terrain/lower-route-ab-passage-v1.png) · [내장 image_gen 프롬프트](../assets/terrain/lower-route-ab-passage-v1.prompt.txt)

원경은 A파트와 같은 청록빛 동굴에 폐수로·육각 문양 기둥·큰 석륜·멀리 흐르는 물줄기를 배치한다. 벽점프 슬롯은 천장에서 내려온 바위와 방패병 발판 밑의 돌출암으로 둘러싼다. 두 벽의 접촉면은 도면에 맞추고, 바깥쪽 암반과 장식은 불규칙하게 다듬는다.

발판은 젖은 청회색 돌과 이끼 군집을 공통으로 쓰고, 양쪽 끝까지 두꺼운 돌층을 유지한다. 골렘 발판과 C 통로는 파인 하부가 남은 통로 연결판 한 장으로 그린다. 방패병 발판의 오른쪽은 벽점프 벽으로 이어지고, 공벌레 발판의 석조 받침은 가시 사이까지 내려간다.

협곡 바닥 전체에 기존 [가시 덩굴](../assets/structures/map1-lower-route/lower-cave-thorn-bed-v1.png)을 두 겹으로 겹친다. 안쪽 줄은 청록색 대기에 잠기고, 앞쪽 줄은 밝은 칼날 끝이 보인다. 발판 위에는 기존 공벌레·방패병·수정 골렘 스프라이트와 작은 석등을 배치한다. 레일과 장착 파츠도 본편에서 쓰는 이미지를 사용한다.

원경은 내장 image_gen으로 제작했다. 현재 본편의 A 왼쪽 출구를 지나 B 전 구간과 왼쪽 C 연결 통로까지 플레이할 수 있다. 본편과 미리보기는 `lower_route_b_art.py`로 같은 발판과 가시를 그린다. 전체 시안은 `.\.venv\Scripts\python.exe -m tools.preview_lower_route_b`로 렌더링한다.

## 진행 순서

| 순서 | 이동과 전투 |
| --- | --- |
| A 연결과 첫 레일 출발대 | 가까운 파츠에 `E`로 유물을 장착하고 왼쪽을 보며 `X`로 친다. 파츠가 위로 솟아 협곡 가운데를 지나고 공벌레 발판 쪽으로 내려온다. 건너편에 정차하면 `E`로 이동한다. |
| 공벌레 발판 | 오른쪽 끝 여유 구간에서 착지한다. 안쪽 공벌레를 지나 왼편으로 들어가면 벽 사이에 도약할 공간이 나온다. |
| 벽점프 상승 | 아래 발판에서 왼쪽 벽으로 도약한다. 오른쪽 벽을 거쳐 다시 왼쪽으로 튕기면 위 발판에 닿는다. 두 발판의 높이차는 410이고 벽 사이 폭은 250이다. 오른쪽 벽 아래는 걸어서 진입할 수 있고, 위쪽은 천장과 이어진다. |
| 방패병 발판 | 발판 오른쪽에서 착지하고 가운데 방패병을 만난다. 발판이 넓어 뒤로 물러서거나 뒤로 돌아갈 수 있다. 왼쪽 끝에 두 번째 레일 출발대를 둔다. |
| 두 번째 레일과 수정 골렘 발판 | 파츠가 방패병 발판에서 출발해 가시 협곡 안쪽으로 내려간다. 낮은 레일을 가로지른 뒤 맞은편 발판 높이로 돌아 올라온다. 골렘은 발판 안쪽에 배치한다. 발판 왼쪽 끝에서 짧은 안전 통로를 거쳐 C로 이어진다. |

몬스터는 착지 여유 구역을 벗어나 자기 발판에 접근하면 활성화한다. 방패병의 체력은 45다. 방패 쪽에서 들어오는 베기는 방패를 휘두르는 중에도 막는다. 플레이어가 뒤에 머물면 방패병은 최대 1.5초 동안 기존 방향을 보며, 그 사이 뒤에서 한 대 맞으면 즉시 플레이어 쪽으로 돌아선다. 수정 골렘의 투사체는 해당 발판의 전투 구역에서만 플레이어에게 피해를 준다.

기존 레일과 같은 직선 파츠와 90도 곡선 파츠를 이어 붙인다. `C`를 누르는 동안 카메라로 이동 중인 유물과 실제 정차 위치를 확인하고 `E`로 이동할 타이밍을 잡는다.

## 가시 추락과 재시도

가시에 닿으면 체력 25 피해를 받고 가장 최근에 안정적으로 착지한 발판의 안전 구역으로 돌아온다. 레일을 건너는 중이었다면 해당 파츠를 출발 정차점에 돌리고 유물을 플레이어에게 회수한다. 공벌레 발판에서 벽점프에 실패했다면 공벌레 발판에서 다시 도약한다. 추락 전에 처치한 몬스터의 상태는 유지한다. 체력이 0이 되면 B 입구에서 재시작한다.

## 배치 치수

오른쪽과 위쪽이 양의 방향이다. 표의 단위는 월드 좌표다.

| 요소 | 배치 |
| --- | --- |
| A 진입 발판 | `x=4460~5000`, 상단 `y=180` |
| 첫 레일 | 출발 `(4620, 280)` → 중앙 최고점 `y=560` → 정차 `(3450, 280)`. 발판 사이 폭 810, 이동 약 2.4초 |
| 공벌레 발판 | `x=3060~3650`, 상단 `y=180`, 폭 590. 착지 구역 `x=3410~3650` |
| 벽점프 | 왼쪽 면 `x=2900`, 오른쪽 면 `x=3150`. 오른쪽 벽 하단 `y=355` |
| 방패병 발판 | `x=2160~2900`, 상단 `y=590`, 폭 740. 착지 구역 `x=2670~2900`, 레일 출발 구역 `x=2160~2350` |
| 두 번째 레일 | 출발 `(2320, 690)` → 중앙 최저점 `y=355` → 정차 `(1160, 690)`. 발판 사이 폭 820, 이동 약 2.5초 |
| 수정 골렘 발판과 C 연결 | 골렘 발판 `x=680~1340`, 상단 `y=590`, 폭 660. 착지 구역 `x=1100~1340`. C 연결은 `x=0~680` |
| 가시 | `x=0~5000`, 가시 끝 높이 약 `y=-200` |

현재 플레이어 물리의 평지 달리기 점프 거리는 약 518, 최고 도약 높이는 약 203이다. 본편 입력 테스트에서 첫 레일 중간 하차 후 가시 복귀, 두 레일 횡단, 벽점프, C 연결부 진입을 확인했다. 실제 충돌은 발판과 벽의 주요 석재를 사각형들로 근사한다.

곡선 반경은 96이고 이동 시간은 현재 레일 파츠 속도 660을 기준으로 산정했다. 세그먼트는 왼쪽부터 등록하고, 파츠를 오른쪽 끝에 초기화하면 기존 왼쪽 타격으로 출발한다. 도면 재생성은 `.\.venv\Scripts\python.exe -m tools.draw_lower_route_b_v2` 명령으로 한다.
