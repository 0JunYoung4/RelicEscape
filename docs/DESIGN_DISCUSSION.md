## 다음에 결정할 순서

1. 체력 0 처리: 재시작 위치, 회복 체력, 수집 상태 유지 범위.
2. 체력 강화: 현재 체력 회복 여부, 전체 배치 수, 반복 강화 여부.
3. 안전 발판: 기록 갱신 조건과 복귀 후 연속 피해 방지.
4. 메인 스테이지: 강화 유물 배치와 필수 진행·선택 탐험 경로.
5. 일반 적과 보스: 공격 전조, 반격 구간과 순간이동 활용.

## 검토 제안

체력 강화 유물을 메인 스테이지의 선택 탐험 경로에 배치하면 탐험이 보스전의 생존 여유로 이어질 수 있다. 이는 제안이며 아직 위치나 배치 수를 확정하지 않았다.

체력 0에서 체크포인트 복귀와 최대 체력 회복, 강화 유물 수집 상태 유지를 다음 논의 후보로 둔다. 이 사망 처리 역시 아직 확정하지 않았다.
