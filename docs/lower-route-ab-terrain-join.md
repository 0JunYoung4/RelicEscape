# 하단 A–B 절벽 연결부

4번 장면의 왼쪽 절벽과 5번 장면의 오른쪽 위 발판은 모두 B 입구의 왼쪽 끝 `x=4460`과 A–B 통로가 만나는 구간이다. 5번은 아래층에서 오른쪽 위를 보는 구도다.

## 확인한 원인

| 사용 이미지 | 원본 | 기존 표시 방식 |
| --- | --- | --- |
| [B 끝단](../assets/terrain/ruin-platforms/root-wedge-v2.png) | RGBA 1774 × 887. 전체에서 알파 0 픽셀 573,852개, 알파 1–254 픽셀 998,744개, 알파 255 픽셀 942개 | [B 지형 렌더러](../lower_route_b_art.py)가 원본 보행선 `[28, 176, 1751]`을 월드 `x=4460–5110, y=180`에 놓는다. 배율은 양축 약 0.377 월드 단위/원본 px, 카메라 0.5에서 약 0.189 화면 px/원본 px다. 투명 여백을 포함한 그리기 범위는 약 `x=4451–5118`이다. |

[구간 그리기 순서](../lower_caves.py)는 B 지형과 A 장면을 그린 뒤 연결부를 그린다. 패스마다 각 이미지는 한 번 호출됐지만 `x=4690–5118`에서 서로 다른 암반 텍스처가 겹쳤다. 특히 `x=4690, 4845, 5000`에서 기존 연결부 정점 알파가 각각 `0, 140, 255`여서, 왼쪽 310 월드 단위에 원화와 끝단의 일부가 함께 보였다.

## 배치 및 재사용 기준

1. 끝단과 중앙부는 같은 보행선에 맞춘다. 여기서는 절벽 끝 `x=4460`, B–통로 충돌 경계 `x=5000`, 통로–A 경계 `x=5900`의 윗면이 모두 `y=180`이다. 중앙 통로 원화의 371행을 이 높이에 맞춘다. 이끼와 잎 끝은 보행선 위로 나올 수 있다.
2. 지형 몸체가 이어지는 구간은 같은 원화와 배율로 만든다. [새 연결부 PNG](../assets/terrain/lower-route-ab-passage-joined-v2.png)는 원화 열 `690–1679`의 990 × 724 RGBA 스프라이트다. 중앙의 원본 배치와 배율을 유지하면서 같은 암반 원화를 왼쪽으로 연장하고, 외곽의 절단면에 짙은 테두리를 넣었다. 원본 중앙 통로와 다른 곳에서 쓰는 B 끝단 PNG는 그대로 사용할 수 있다.
3. 편집 시 끝단에서 원경과 암반을 가르는 외곽 마스크를 그린다. 보행면과 암반 몸체를 알파 255로 채우고, 바깥쪽 실루엣의 가장자리 픽셀에만 부분 알파를 둔다. 원경과 아래쪽 그림자의 전환은 암반 몸체 바깥에서 처리한다. RGB로 합쳐진 원화에 구멍이 필요하면 원화 자체의 암반과 원경을 나눈 뒤 외곽 마스크를 갱신한다. 이 구간에서는 [베이크 스크립트](../tools/bake_lower_route_ab_passage.py)의 윗면 탐색과 하단 윤곽이 그 역할을 한다.
4. 연결된 장면에서는 B 입구의 기존 끝단과 잔해 표시를 끈다. 새 스프라이트를 같은 월드 원점에서 한 번 그린다. 카메라 좌표는 목적지 사각형에만 적용한다. 단독 B 미리보기는 기존 끝단을 사용한다. A 쪽 오른쪽 배경 전환과 B 아래층 돌바닥은 이번 두 장면의 상단 절벽과 별도 구간이다.

원화에서 다시 만들려면 저장소 루트에서 `python -m tools.bake_lower_route_ab_passage`를 실행한다. `--terrain-preview <경로>`를 추가하면 원경·깊은 그림자를 제외한 접합부 확인용 PNG도 출력한다.

## 검증

- 논리 해상도 960 × 540, 카메라 배율 0.5로 수정 전후를 비교했다. 4번 카메라 원점은 `(4272, -270)`, 5번은 `(3352, -740)`이다. 단색 배경에는 대상 암반만 추출해 그렸고, 전체 배경 비교에는 실제 구간 렌더러를 사용했다. SDL 소프트웨어와 Windows Direct3D 11에서 확인했다.
- 실제 구간 업데이트에 방향 입력을 주입해 월드 `x=5550→4500`, `4500→5550`을 각각 110프레임 주행했다. 보행 높이 `y=180`과 접지를 유지했고 카메라는 구간을 연속으로 따라갔다. 절벽에서는 플레이어 충돌 상자의 오른쪽이 `x=4460`에 도달했을 때 접지가 풀렸다. 보행선 오버레이와 이동 프레임에서 접합부에 틈이나 이중 암반이 보이지 않았다.
- 테스트는 출력 PNG의 보행면과 암반 몸체에서 알파 255, 절벽 바깥에서 알파 0을 검증한다. 전체화면에서의 수동 키보드 플레이는 수행하지 않았다.
