# RelicEscape 초기 기획서

- 버전: v0.1
- 작성일: 2026-10-31
- 상태: 초기 콘셉트 정리
- 제목: RelicEscape (가칭)

이 문서는 현재까지 합의한 게임의 기본 틀과 앞으로 결정할 항목을 기록한다. 제안으로 표시한 설정·규칙·규모는 아직 확정하지 않았으며, 기능이 구현되었다는 의미는 아니다.

## 1. 한 문장 소개

귀환 지점을 설치하는 유물과 소모성 순간이동 파편을 활용하여, 함정과 몬스터로 가득한 유적을 탐험하고 탈출하는 2D 횡스크롤 게임.

## 2. 합의한 기본 방향

| 항목 | 기본 방향 |
| --- | --- |
| 개발 환경 | Python, pico2D |
| 장르와 시점 | 2D 횡스크롤 탐험 액션, 일부 퍼즐 |
| 배경과 목표 | 함정과 몬스터가 있는 유적에서 탈출 |
| 메인 능력 | 키를 눌러 현재 위치에 귀환 지점을 설치하고, 같은 키를 다시 눌러 해당 지점으로 이동 |
| 보조 아이템 | 맵에서 획득하며, 던진 지점으로 이동하는 1회성 순간이동 아이템 |
| 능력 활용 | 탐험, 함정 통과, 전투에서 위치를 선택하는 데 활용 |
| 실행 목표 | 데스크톱과 노트북에서 동일한 프로젝트를 실행 |

### 참고하는 플레이 감각

- 할로우 나이트: 서로 연결된 공간을 탐험하고 새로운 통로를 발견하는 느낌.
- 마인크래프트의 엔더 진주: 던진 지점으로 이동하는 소모성 아이템의 직관적인 사용 방식.

작품의 캐릭터·스토리·맵·이미지·음원은 자체 게임에 맞게 구성한다. 전체 맵 규모와 전투 범위는 별도로 정한다.

## 3. 핵심 재미와 플레이 흐름

플레이어가 지형을 관찰하고 돌아갈 위치를 준비한 뒤, 위험한 장소에 진입해 탐험의 성과를 얻는 것이 핵심이다. 퍼즐은 탐험 흐름 안에서 능력을 활용하는 상황으로 배치한다.

기본 흐름:

주변 관찰 → 귀환 지점 설치 → 탐험 및 진입 → 아이템 획득 또는 장치 작동 → 필요 시 귀환 → 열린 길로 진행.

- 탐험: 처음 보는 공간에 진입하고, 숨은 보상과 연결 통로를 발견한다.
- 판단: 귀환 지점을 남길 위치와 소모 아이템을 사용할 시점을 선택한다.
- 액션: 함정과 몬스터를 피하거나 상대하며 유리한 위치를 확보한다.
- 퍼즐: 귀환과 투척 이동을 이용해 지형이나 장치의 제약을 해결한다.
- 성취: 돌아온 뒤에도 획득물이나 열린 통로 등 탐험의 결과를 확인하게 한다. 구체적인 상태 유지 규칙은 아래 제안에서 검토한다.

## 4. 두 이동 수단

### 4.1 귀환 유물

확정한 동작: 첫 입력으로 현재 위치에 귀환 지점을 설치하고, 같은 키의 다음 입력으로 해당 위치에 돌아온다.

초기 규칙 제안:

- 귀환 지점은 동시에 한 개만 유지한다.
- 안정된 지면 위에 설치한다.
- 귀환하면 흔적이 사라져 다시 설치할 수 있다.
- 이동은 플레이어 위치에 적용하고, 획득한 아이템과 작동한 장치는 유지한다.
- 투척형 순간이동을 사용해도 기존 귀환 지점은 유지한다.
- 쿨타임·사용 자원·최대 귀환 거리는 시험 플레이 후 필요성을 판단한다.

결정할 것: 방 사이의 귀환 허용 범위, 흔적 취소 방법, 사망 시 흔적 처리.

### 4.2 투척형 순간이동 아이템

확정한 동작: 맵에서 획득하는 1회성 아이템을 던져 해당 지점으로 이동한다. 명칭은 미정이며 문서에서는 '순간이동 파편'으로 부른다.

초기 규칙 제안:

- 조준한 방향으로 포물선을 그리며 날아간다.
- 벽을 통과하지 않고 지형에 처음 닿았을 때 이동을 시도한다.
- 충돌 지점 주변에서 플레이어가 들어갈 수 있는 빈 공간으로 이동한다.
- 정상적인 순간이동이 성립하면 아이템 한 개를 소모한다.
- 유효한 도착 공간이 없거나 맵 밖으로 사라지면 이동하지 않고 아이템을 반환한다.
- 사용 전 조준 방향을 보여주며, 예상 궤적과 도착 위치 표시는 필요에 따라 추가한다.

결정할 것: 투척 거리, 소지 개수, 몬스터에 닿았을 때의 처리, 위험 지형 도착 허용 여부, 사망 후 소모량 복구 방식.

### 4.3 조합 예시

1. 낭떠러지 앞의 안전한 곳에 귀환 흔적을 남긴다.
2. 파편을 던져 건너편으로 이동한다.
3. 함정이나 몬스터를 통과해 출구를 여는 장치를 작동한다.
4. 귀환 능력으로 원래 위치에 돌아온다.
5. 열린 통로로 진행한다.

이는 조합을 설명하기 위한 예시이며 실제 맵과 필수 공략으로 확정한 것은 아니다.

## 5. 세계관과 이야기 후보

아래 설정은 보강을 위한 후보이다.

유적은 과거에 공간 이동을 연구하던 시설이었다. 주인공이 유물을 발견해 작동시키면서 잠들어 있던 방어 장치와 수호체가 깨어나고, 입구가 봉쇄된다. 주인공은 유물의 귀환 기능과 유적 곳곳에 남은 소모성 파편을 이용해 출구로 향한다.

이 설정은 귀환 유물, 순간이동 파편, 함정, 몬스터를 하나의 배경으로 연결하기 위한 출발점이다.

추가로 정할 내용:

- 주인공의 정체와 유적에 들어온 목적.
- 유물을 얻게 되는 계기와 입구가 막히는 구체적인 사건.
- 유적이 버려진 이유와 몬스터의 정체.
- 귀환 흔적과 파편의 이름 및 공통된 시각적 특징.
- 최종 출구를 여는 조건과 탈출의 결말.

## 6. 탐험과 퍼즐 설계 제안

- 이동하는 방, 주변을 살펴보는 방, 함정·전투 구간 사이에 짧은 퍼즐을 배치한다.
- 새로운 능력을 계속 추가하기보다, 두 이동 수단과 지형의 조합을 확장한다.
- 귀환으로 안전한 곳에 돌아왔을 때에도 획득물·장치·지름길 등 성과가 남도록 한다.
- 주요 경로는 소모 아이템을 다 써도 진행할 수 있는 구성을 우선 검토한다.
- 파편이 반드시 필요한 학습 구간에는 재공급이나 구간 재시작 수단을 둔다.
- 막다른 길에는 보상이나 새 정보 등 들어갈 이유를 제공한다.

| 상황 후보 | 플레이어의 판단 |
| --- | --- |
| 아래로만 내려갈 수 있는 통로 | 내려가기 전에 어디에 귀환 지점을 남길까? |
| 건너면 무너지는 다리 | 돌아올 방법을 준비했는가? |
| 한쪽 문을 열면 다른 문이 닫히는 장치 | 어느 문 너머에 흔적을 남겨야 할까? |
| 위험한 함정 너머의 선택 보상 | 파편을 써서 보상을 얻을 가치가 있을까? |
| 적이 통로를 지키는 구간 | 직접 상대할지, 순간이동으로 다른 위치를 잡을지? |

## 7. 첫 시험 구간과 개발 범위 제안

첫 시험 구간에는 시작 발판, 귀환 설치 위치, 건너편 장치, 함정 하나, 출구를 배치한다. 파편과 귀환의 조합이 재미있는지 먼저 확인하고 몬스터를 추가한다.

첫 시험 구간의 확인 기준:

- 귀환 흔적과 귀환 가능 여부를 알아볼 수 있다.
- 투척 후 도착할 위치를 이해할 수 있다.
- 지형 안에 끼이지 않고 이동한다.
- 두 능력을 조합해 장치를 작동하고 출구에 도달한다.
- 파편을 잘못 사용한 뒤에도 재시도할 수 있다.

초기 완성 규모 후보는 중심 방 하나와 주변 구역 두 곳, 전체 6~8개 방, 간단한 적 1~2종, 귀환 활용 상황 3종이다. 이는 규모 검토용 제안이며 개발 기간과 시험 결과에 따라 조정한다.

## 8. 개발 순서 초안

1. 사용할 Python·pico2D 버전을 정하고 기본 창을 실행한다.
2. 플레이어 이동·점프와 지형 충돌을 만든다.
3. 귀환 지점 설치·표시·복귀를 만든다.
4. 파편 투척과 안전한 도착 처리를 만든다.
5. 첫 시험 구간의 장치와 출구를 연결한다.
6. 함정과 간단한 적을 추가하고 조작감을 확인한다.
7. 연결된 방, 보상, 지름길을 확장한다.
8. 데스크톱·노트북 실행을 확인하고 시각·음향 표현을 보강한다.

작업 단위마다 실제 동작을 확인하고 변경 내용을 커밋한다. 구체적인 일정은 개발 가능 기간을 확인한 뒤 정한다.

## 9. 두 컴퓨터에서 작업하기 위한 준비

- 같은 Python·pico2D 버전을 기준으로 실행 환경을 구성한다.
- 첫 실행 버전에 의존성 목록과 설치·실행 설명을 추가한다.
- 이미지·소리·맵 경로는 특정 컴퓨터의 절대 경로에 고정하지 않는다.
- 가상환경은 Git에 올리지 않고 각 컴퓨터에서 생성한다.
- 초기 플레이 가능 버전부터 노트북에서 직접 실행을 확인한다.
