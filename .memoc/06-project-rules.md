- 2026-11-25 사용자 지정: 맵을 만들거나 수정할 때 [장식 23종](../assets/terrain/moss-grotto-floor-decor/README.md)을 기본으로 활용한다. 검은 윤곽, 짙은 청록 그림자, 둥근 불규칙한 형태, 짧은 이끼빛을 새 자산에도 적용한다.

- 2026-11-25 사용자 지정: 뒷배경, 바닥·발판, 천장, 벽, 맵 조형물, 가까운 전경을 각각 독립 제작·렌더링한다. 한 번에 한 레이어씩 만들고 단독 시안을 확인한다. 원경은 지형 뒤에, 전경은 캐릭터 앞 양옆에 그린다. [맵 제작 세부 기준](../docs/reference-production-guide.md#맵-미술-제작과-렌더링-기준)

- 2026-11-23 사용자 요청: 저장소를 변경한 작업은 마무리할 때마다 Git 커밋을 만든다. 해당 작업에서 만든 변경만 포함한다.

- 2026-11-23 자산 정리 시 캐릭터 콘셉트·설정·기획 자료를 삭제하지 않는다. 미사용 구버전·중간 산출물은 별도 보관 폴더로 옮기고 원래 경로를 기록한다. 명백히 불필요한 임시 파일만 삭제하며, 게임의 JSON 간접 참조와 동적 파일명도 확인한다.

- 오프닝은 문양 조사 E 이후 자동 연출이며 이때 주인공은 무기를 들지 않는다. 관찰·느린 접근·손 접촉 뒤 균열 발광·흔들림·바닥 붕괴·수직 추락으로 연결한다. 순서대로 제작하며 현재 구현은 접촉 자세까지다.

- Keep `AGENTS.md` and `CLAUDE.md` as short entry files; durable context belongs under `.memoc/`.
- Do not track generated output folders such as `out/`, `.next/`, `dist/`, `build/` unless the user explicitly asks.
- Update `.memoc/04-handoff.md` after substantial work so the next agent can resume quickly.
- Use `.memoc/05-done-checklist.md` before saying substantial work is complete.

## 맵 레벨 디자인과 환경 아트

- 2026-11-26 사용자 지정. 사용자가 방의 목적과 분위기, 핵심 기믹, 진행 조건을 주면 에이전트가 방의 형태, 진입과 이탈 동선, 발판과 통로, 조형물의 형태, 원경·중경·전경 배치를 구체적으로 설계한다.
- 소품의 종류·위치와 세부 미술은 공간의 용도와 공통 미술 기준에 맞춰 판단한다. 여러 방향이 가능하면 적합한 안과 선택 근거를 제시하고 그 안으로 검토할 수 있는 초안을 만든다. 사용자에게는 진행이나 분위기를 좌우하는 방향과 검토 결과를 보여준다.
- 조형물은 주변 지형·식생·빛과 함께 설계한다. 사용할 기존 자산과 새 이미지의 역할, 크기, 배율, 부착 기준점, 레이어를 에이전트가 정한다.
- 방 하나를 먼저 완성하고 실제 게임 화면과 이동 중 깊이감·통일감·플레이 가독성을 검토해 수정한다. 직접 볼 수 없으면 필요한 카메라 구도와 플레이 상태를 구체적으로 지정해 캡처를 요청한다.
- 완료한 작업 단위마다 한국어 메시지로 로컬 커밋한다. 푸시는 사용자의 별도 요청이 있을 때 진행한다.

- 2026-11-26 사용자 지정. 맵 미술·합성·조명·전경·카메라 작업은 [맵 미술과 렌더링 공통 지침](../MAP_VISUAL_GUIDE.md)을 참고한다. 기존 플레이 판정과 요청 범위를 유지하며, 한 방의 팔레트나 효과를 다른 맵에 강제하지 않는다. 거리 관계를 먼저 잡고, 정지 화면의 대비·색·겹침과 움직일 때의 시차를 같은 깊이에 맞춘다. 시차 출발값과 축별·줌·기준점 계산 및 검수는 공통 지침을 따른다.

## Project-Specific Rules

- 2026-11-25 전투방은 분리된 원경·바닥·벽·천장·설치 장식·전경 레이어를 사용한다. 바닥에 풀을 붙이고 벽과 천장에 덩굴을 배치하며 암벽 내부를 검게 가린다. 현재 하강 입구는 전멸 뒤 중앙 바닥이 무너지는 방식이다.

- 2026-11-23 유물 획득 지점은 천장 틈에서 새어 들어오는 강한 빛을 유물 쪽으로 모아 신비함을 강조한다. 유물의 밝기·후광과 받침대 주변 반사광이 시선을 이끌어야 한다.

- 2026-11-25 공벌레·수정 골렘·방패병은 유효 피격 시 기본 베기 사거리만큼 실제 몸체가 밀린다. 벽과 발판 경계에서 멈추며, 방패병은 방패에 막힌 공격에는 밀리지 않는다.

- 2026-11-23 덩굴 그림자는 화면 상단 장식이 아니라 맵 천장에 고정한다. 카메라는 천장을 보이게 조정하지 않고 캐릭터 위치를 따라간다. 천장 가시성에 따라 화면 고정/월드 고정 기준을 전환하지 않는다.

- 2026-11-23 유물 통로 지면 기둥은 기존에 보관한 할로우 나이트 녹색 거리 참고 느낌으로 제작한다. 어두운 직사각형 돌몸체에 둥근 잎·이끼와 덩굴을 두르고, 밑동은 땅에서 솟은 모습으로 연결한다.

- 2026-11-23 최신 예외/윤곽: 문틀 끝은 덩굴을 별도로 덧붙이지 않는다. 바닥·천장 표면은 자갈과 이끼의 작은 불규칙한 높낮이가 자연스러우므로 반드시 일직선으로 맞추지 않는다. 보이는 윤곽은 다듬되 현재 이동감과 시작 동굴/착지방 보존 범위는 유지한다.

- 2026-11-23 벽 모서리의 직각 선은 덩굴과 잎 장식으로 자연스럽게 가린다. 기존 벽/발판 이미지와 실제 충돌은 유지하며, 장식은 캐릭터 뒤에 배치한다. 시작 동굴과 최초 착지방의 보존 범위는 계속 유지한다.

- 2026-11-23 최신 미술 범위: 시작 동굴뿐 아니라 처음 떨어져 깨어나는 착지방도 기존 그대로 둔다. 옆 통로로 넘어간 뒤부터 새 텍스처를 적용한다. 현재 벽 이미지와 발판은 승인 상태다. 이번 조정은 새 이미지 제작 대신 기존 벽의 표시 크기만 크게 하며 발판은 유지한다.

- 2026-11-23 미술 방향: 시작 동굴은 기존 모습으로 유지한다(사용자 명시 예외). 추락 이후 구간은 제공된 녹색 거리 참고의 검은 지형 내부·이끼/작은 돌 테두리·푸른 원경·겹친 전경 뿌리와 덩굴을 기준으로 통일한다. 기존 방/충돌 구조는 유지한다. 기준 문서 docs/environment-art-direction.md.

- 2026-11-23 덮개와 고정 연결부 몸체를 전부 보여주지 않는다. 주변 바닥과 같은 그림자에 아래를 자연스럽게 가리고, 열린 윗면·구멍만 보이게 한다. 별도의 사선/삼각형 접합 그림자는 사용하지 않는다.

- 2026-11-23 최신 두께 요청: 하강 덮개는 전투방 입구를 막는 바위의 가로 두께와 같은112로 한다. 깊어진 덮개 홈과 고정 턱도 맞추고, 우측 개방·접근 조명·바닥 연결은 유지한다.

- 2026-11-23 최신 보정: 덮개는18보다 두꺼운32로 하되 상판만 이동한다. 고정 연결부의 네모난 블록 경계를 없애고 기존 바닥의 돌 결/색이 넓게 이어지며 하단은 통로 암벽과 자연스럽게 겹치도록 한다. 접근 조명은 유지한다.

- 2026-11-23 최신 수정: 맨 위 얇은 상판만 오른쪽으로 움직이고 아래 고정 턱·암벽은 그대로 둔다. 입구220/하강 통로180으로 좁혀 연결부를 구분한다. 덮개 개방과 지하 밝기는 분리한다. 열린 뒤에도 멀리서는 검게 유지하며 주인공이 구멍 가장자리에 접근하면 서서히 밝힌다. 높은 발판 위에서는 미리 밝히지 않는다.

- 2026-11-23 하강 덮개는 바닥과 같은 재질의 한 장짜리 바위로 만들고 오른쪽으로 슬라이드해 연다. 닫힌 동안 아래 통로는 어둠에 가리고, 열리면 통로 공간과 얇은 벽면만 보인다. 방과 하강 통로의 좌우 암벽 내부는 검게 가린다.

- 2026-11-22 올라오는 돌벽의 오른쪽 면·상단을 기존 문틀 벽면에 맞춘다. 그림·충돌·먼지 발생 경계도 통일한다.

- 2026-11-22 돌벽 상승·하강 때 지면에서 먼지가 퍼지고 화면이 살짝 흔들려 무게감을 준다. UI는 고정하며 정지 순간의 진동은 짧게 감쇠한다.

- 2026-11-22 최신 수정: 전투방 중앙에서 적이 등장하면 입구에 돌벽이 바닥에서 올라와 봉쇄한다. 전부 처치하면 돌벽이 내려가고 기존 아래 통로도 개방한다. 기존 철창은 사용하지 않는다. 유물/귀환으로도 전투 중 문밖에 빠져나가지 못하도록 한다.

- 수정 골렘은 피격 모션과 경직을 생략한다. 비치명 공격의 넉백 중에도 수정 충전·발사 타이밍이 진행되며, 치명타에서 죽음으로 전환한다.

- 2026-11-22 공벌레의 죽음은 몸을 둥글게 말고 돌껍질이 푸른색 사각 픽셀 조각으로 흩어지며 사라지는 형식이다.

- 2026-11-22 모든 몬스터는 생성·움직임·피격·공격·죽음의 5종 애니메이션을 기본 구성으로 갖추되, 최신 사용자 지정 특성 예외(골렘 피격/경직 없음)를 우선한다. 기존 몬스터 보완과 이후 새 몬스터도 동일 기준으로 관리한다. 종류별 프레임 수·시간·표현은 각 몬스터에 맞추며 현재 파일명을 일괄 변경하지 않는다.

- 2026-11-22 발판 가로 폭을 바꿀 때 세로 두께를 불필요하게 납작하게 줄이지 않는다. 전투방 돌 발판의 현재 두께는 기존 통로 발판과 같은 90 월드 단위다.

- 2026-11-22 플레이어와 충돌하는 방의 양벽은 수직 직선으로 제작하고 곡선을 최대한 피한다. 이미지 벽면과 실제 충돌 경계를 일치시킨다. 다음 전투방 입구는 직각 돌 문틀 형태다.

- 2026-11-22 다음 전투방의 입구는 왼쪽 벽을 관통하는 수평 통로다. 원경 배경과 닫힌 돌 덮개를 유지하고 바닥 아래 샤프트는 게임 렌더에서 어둡게 가린다.

- 2026-11-22 몬스터 몸 접촉은 기본 피해를 준다. 뒤집힌 공벌레는 영구 정지하지 않고 잠시 후 기립해 순찰·공격을 재개한다.

- 2026-11-22 일반 몬스터 체력바는 숨긴다. 돌·바위 몬스터를 공격해 명중하면 주인공을 공격 반대 방향으로 짧게 밀어 단단한 타격 반동을 표현한다.

- 2026-11-22 사용자가 확정한 전체 맵 제작 기준은 `docs/world-map-progress-2026-11-22-v2.png`다. 이후 맵 제작은 이 구조의 구역 배치와 연결 관계를 따른다. 세부 방 크기·지형·장치는 제작 시 조정하되, 전체 연결 변경은 사용자의 후속 지시를 기준으로 한다.

- 2026-11-22 지도는 첫 구간 상세 원본(`docs/first-boss-map-plan-reference-v1.png`)을 전체 초안보다 우선한다. 추락 구멍은 문양 바로 앞이다. 중앙 통로는 지하 전체 구역의 연결 허브로 설계하고 시작 동굴·문양 방과 직접 잇지 않는다. 지도 요청은 기존 방·통로 배치 위에 구현 범위를 표시하는 방식으로 답한다.

- 문양 벽의 외곽 연결부는 유지하되 균열은 문양 안쪽에 한정하지 않고 석재 벽 전체의 위·아래·양옆에 분포시킨다. 엔딩에서 이 문양 벽을 부수고 탈출할 계획이므로 큰 조각으로 갈라질 수 있는 구조적인 금으로 표현한다. 초기에는 아직 무너지거나 뚫리지 않은 상태다.

- 기존 벽과 문양 벽을 합칠 때 원본 배경을 처음부터 다시 그리지 않는다. 기존 암벽을 그대로 보존하고 문양이 들어가는 국소 영역만 편집·합성한다.

- 문양 벽과 후면 암벽의 재질·그림체가 분리되어 보이지 않게 한다. 최신 요청은 후면 배경에 문양 벽까지 함께 그린 통합 이미지 시안이다.
