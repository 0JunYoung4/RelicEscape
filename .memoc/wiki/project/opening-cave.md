# 초기 동굴

`main.py`의 기본 흐름은 타이틀 → `run_opening_cave`이다. `--test-room`을 주면 기존 `run_game` 시험 맵을 사용한다. 각 루프의 Esc는 타이틀 복귀, 창 닫기는 종료다.

## 지형과 렌더

- `opening_cave.py`: 폭 6000, 바닥 y420, 시작 x380. 점점 높아지는 천장과 문양 벽 앞 약 x5764.29의 경계로 충돌을 구성한다. 카메라 0.5배, Camera.y160으로 바닥을 화면 y130에 유지한다.
- 현재 암벽은 원본 `opening-cave-backdrop-v2.png`에 문양만 합성한 `opening-cave-backdrop-rune-v7.png`다. 기존 크기와 색상 배율 `(76,80,88)`을 유지한다. 자연 바닥과 아래 음영, 카메라와 이동 제한도 유지한다.
- 텍스처 색상 배율로 배경과 지형을 어둡게 한다. 캐릭터는 나중에 기존 밝기로 그린다. 입구에는 약한 푸른빛을 둔다.
- 천장 간격은 입구 440, 안쪽 740이다. x600~4600에서 `ceiling_height_at`의 smoothstep으로 넓어지며 40 단위 `CEILING_SPANS`로 충돌/그림을 맞춘다. 종유석도 같은 구간을 따라 이미지를 잘라 연결한다. 입구는 세로 0.35배, 안쪽은 0.7배로 점프 실루엣을 가리지 않게 한다. 종유석에는 충돌이 없다.
- 문양 벽은 통합 배경에 포함되어 별도로 그리지 않는다. 확대 영역은 원본 이미지의 (2044,237,128,402)이다. v6는 외곽과 벽 접합을 보존하고 문양 내부 다각형에만 각인·홈 음영·세부 균열을 더했다. 자산 변경 bbox는 (2063,372,2146,526)이다. 원본 타이틀·이동 제한·문양 크기는 유지한다.

## 문양 조사 자동 연출

`opening_cutscene.py`의 `SigilApproach`를 `run_opening_cave`가 소유한다. 벽 접촉 위치에서 420 월드 단위 이내, y420 바닥에 선 상태일 때 E 표시와 조사 입력이 활성화된다. E는 기존 공격·검기·숙임 상태를 초기화하고 오른쪽을 보게 한다.

관찰 0.55초 → 속도 90의 자동 걷기 → 손 뻗기 1.18초 → 문양 발광·흔들림 → 맨손 뒷걸음질 → 방어 자세 순서다. 플레이어 중심의 종점은 `END_WALL_X - STANDING_HITBOX_WIDTH / 2`다. 한 번의 큰 dt에도 단계를 넘겨 처리하며 벽을 넘지 않는다. 연출 도중 `Player.update`를 호출하지 않아 이동·점프·공격·추가 E/Q 입력이 동작하지 않는다. R은 연출과 플레이어를 함께 초기화한다.

전용 맨손 v3 시트는 16프레임(걷기 8 + 관찰·손 뻗기 8)이며 고개와 시선이 살짝 오른쪽 위를 향한다. JSON으로 일반 캐릭터 그리기를 대신하며 발 접점과 신장을 맞춘다. 걷기 11fps로 기존 주기를 유지하고 손 뻗기 총 1.18초도 유지한다. 원본과 제작 정보는 [캐릭터 문서](../../../docs/PLAYER_SPRITES.md)에 있다. 손이 닿은 프레임에서 발광과 진동을 시작한다. `recoil`에서 16프레임·9fps로 190만큼 후퇴하고 `braced`에서 멈춘다. v2 전체 82개 테스트, v3 관련 4개 테스트와 SDL 동작 미리보기를 확인했다.

## 범위와 확인

엔딩 계획은 이 문양 벽을 부수고 탈출하는 것이다. 현재 적용한 v7에는 문양 위·아래·양옆의 돌 면 전체에 구조적인 균열이 있다. 외곽 접합과 문양의 기본 선은 보존했다. 실제 벽 파괴/탈출 제어는 미구현이며 초기 이동 제한은 유지한다.

손 접촉 후 중앙과 가장자리를 함께 밝힌다. 세 번의 진동이 빛을 끌어올리고 강진에 바닥이 일곱 조각으로 떨어진다. 구멍 폭은 340이며 화면 밖으로 추락한 뒤 통로 전용 카메라와 배경으로 컷을 전환한다. 가로 4096인 하단 방 바닥에 착지한다. R로 시작 위치 복귀, Ctrl+H로 충돌 경계 표시, F11로 창 모드 전환을 사용할 수 있다. E는 문양 조사에 사용하고 유물 획득 전이므로 Q는 동작하지 않는다.

`tests/test_opening_cave.py`는 기본 진입/재진입, 이동/재시작, E/Q 무효, 바닥/끝벽 충돌, 배경 어둡게 처리와 카메라 양끝 렌더를 확인한다. 기존 시험 맵 통합 검사는 `main(test_room=True)`로 유지한다. 총 78개 테스트 통과, SDL 소프트웨어 렌더 세 위치를 시각 확인했다.
