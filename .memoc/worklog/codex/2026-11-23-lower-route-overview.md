# 하단 연습길 전체 환경 시안

- 전투방 하강 착지 → 왼쪽 하단 연습길 → B1 전체 환경 이미지를 내장 image_gen으로 제작했다.
- 결과: [이미지와 제작 기록](../../../assets/concepts/map1-lower-route-overview-v1.md), 동명 PNG와 정확한 프롬프트.
- 오른쪽 착지, 기둥·가시 연습, 석등 전실, 왼쪽 보스방 순서를 반영했다. 폐아치·수로·폭포·기둥을 후경에 추가했다.
- 게임 소스·충돌·맵 진행 변경 없음. 기존 다른 작업의 변경 파일은 커밋에 포함하지 않는다.
- memoc 검색 래퍼가 응답하지 않아 기존 세션 요약을 읽고 수동 기록했다.
