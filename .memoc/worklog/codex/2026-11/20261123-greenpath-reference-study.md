## 검증

45개 이미지 디코드·크기·해시 및 고유 SHA-256 확인. 녹색 거리39장 중 개발 중 공식 자료3장. 같은 공략 연속 장면은 서로 다른 방으로 세지 않음. HTML45카드·54개 이미지 참조, CSV45행, 새 문서/갤러리 로컬 링크 누락0. JS 문법과 git diff --check 통과. 전체45장 연락표와 대표8개 주석·확대 자료를 시각적으로 확인. 자료 폴더 약20.6MiB.

브라우저 미리보기는 로컬 HTTP 접속 타임아웃, file 프로토콜은 도구 보안 정책 차단. 다른 브라우저나 우회 경로는 시도하지 않음. 실제 필터/모달 클릭과 브라우저 레이아웃 검증은 미완료. 이미지와 문서 자체는 로컬 보관 완료.

memoc 래퍼는 로컬 런타임 부재 및 npx 미탐지로 search/work/ingest/lint-wiki 사용 불가. 필요한 메모리와 작업 로그만 직접 작성하고 링크를 검사함. 기존에 진행된 기둥·천장·카메라 작업의 코드/테스트/메모리 변경은 보존함.
