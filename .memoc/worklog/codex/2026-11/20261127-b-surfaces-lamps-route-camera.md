# B 발판·석등과 통로 카메라

사용자가 기존 잔랙은 없다고 직접 확인하고 발판 화풍·작은 조명·중앙 카메라를 지적했다. 내장 ImageGen으로 B 발판5개를 각각 투명 편집해 별도 팩으로 연결했다. 공유 원화·지형·레일·장치 데이터는 보존했다. 석등3개를190월드 높이로 키우고 레일 입구/착지 위치를 비켜 배치해 접촉 그림자·호박빛·바닥 반사를 적용했다.

하단 통로는0.45줌/발22%/상승44%·하강16% 경계와 시간 보간을 적용했다. 짧은 점프는 화면을 유지하고 명시 배치·순간이동은 스냅한다. 전투방 기본0.5는 유지한다. 높아진 시야의 B 천장과 A–B 연결부 상단6px를 천장 내부로 가렸다.

전체229개와 카메라 최종7개 통과. 같은카메라15장 기록 일치, 정상0.45구도5장 검수. SDL B1207/A779/C565의 점프·두 레일·유물·비밀방·체크포인트·구역 복귀를 확인했다. A 연결부는 상단6px 외 픽셀 불변을 재확인했다. 전체화면 장시간 수동·추가 광원 프레임 비용은 이번에 측정하지 않았다. memoc CLI는 기존 DNS 실패로 사용 불가하여 필요한 상태·결정·규칙·인계 문서만 직접 갱신했다.
