# 전투 시작 시 입구 봉쇄와 전멸 후 해제

2026-11-22, Codex.

- 중앙±80 조우 발동에 맞춰 왼쪽 돌 문틀에 철창을 내려 일시 봉쇄한다. 초기에는 자유 출입, 전투 중에는 철창 충돌/방 전환 제한, 전멸 후 철창 상승·하강 덮개 개방이다.
- COMBAT_ENTRANCE_BARRIER가 문과 상부 벽을 겹쳐 막아 숙이거나 점프로 우회할 수 없다. 충돌은 즉시 닫고 시각 철창은0.35초 하강, 전멸 후0.35초 상승 완료 때 충돌을 제거한다. 아래 덮개는 기존0.7초 유지.
- 단순 문만 막으면 미리 설치한 유물이나 Q 귀환으로 우회할 수 있어, 시작 시 travel.reset으로 설치/귀환 흔적을 회수하고 진행 중 allows_relic_destination으로 철창 밖 목적지를 거부한다. 방 안 유물 이동은 가능하다.
- 같은 인스턴스는 전멸 후 개방 상태 유지, 새 R/사망 인스턴스는 조우 전 개방 상태. 진행 중인 방에 직접 enter하는 경로는 철창 안쪽에 안전 스폰한다.
- 새 이미지 생성 없이 native SDL 금속색 사각 도형과 하이라이트/볼트로 철창을 그렸다. docs/combat-gate-before/locked/cleared.png 및 comparison.png를 실제 SDL로 저장하고 검토했다.
