# B1 보스 시작 포효

- 바위 충돌로 깨어난 뒤 고개를 위로 젖히고 양쪽 집게를 들어 벌리는 2초 모션을 제작했다. 사용자 요청에 따라 기존 얼굴을 사용하고 입 형태를 추가하지 않았다.
- [포효 폴더](../../../../assets/concepts/b1-hermit-crab/roar-v1/README.md)에 보스, 공기 파동, 발밑 먼지·자갈을 24fps 투명 WebP와 PNG 시트로 분리하고, 기존 둥지의 합성 GIF를 만들었다.
- pixelfx 외부 저장소는 GitHub DNS 조회 실패로 가져올 수 없어 효과를 Pillow로 직접 렌더링했다. 자갈에는 기존 천장 바위 파편을 사용했다. PNG와 WebP의 알파 및 2초 타이밍, 합성 자세와 파동을 검수했다.
- 본편 B1 전투 연결은 후속 작업이다. 연출 순서와 재생성 명령은 포효 폴더에 기록했다.
