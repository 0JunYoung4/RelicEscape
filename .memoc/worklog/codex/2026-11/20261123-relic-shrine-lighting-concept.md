# 유물 제단 조명 시안 v2

- 사용자 요청: 유물 쪽 빛을 강화하고, 천장 틈으로 빛이 새어 들어와 유물의 신비함을 강조한다.
- v1의 기본 배율 SDL 배치 화면을 내장 imagegen으로 편집했다. 천장 오른쪽 위 작은 균열, 파손된 봉인석 상단을 지나 유물로 내려오는 청백색 빛줄기, 부유 먼지, 유물의 청색 중심/후광, 받침대·이끼 반사광과 주변의 어두운 대비를 추가했다.
- `assets/concepts/relic-acquisition-shrine-lighting-v2.png`는1672×941 전체 장면 콘셉트다. 원래 구조물/유물/캐릭터의 배치와 기본 디자인을 참조했다. 정확한 프롬프트와 입력 출처/상태 JSON을 같은 이름으로 저장했다.
- 생성 원본의 SHA256과 프로젝트 복사본이 일치하고 PNG 디코드/크기를 확인했다. 시각 검토로 천장 광원·유물 강조·반사광을 확인했으며 git diff --check 통과.
- 현재는 디자인 수정 요청의 결과물이다. 실제 게임 조명·통로·충돌·유물 획득 코드와 구조물 투명PNG는 수정하지 않았다. v1 미리보기 도구도 그대로이며 v2는 해당 도구로 재생성되지 않는다.
- `docs/environment-art-direction.md`에 최신 조명 시안과 생성 방식/적용 상태를 명시했다. memoc 런타임/npx 부재로 관련 최소 기록만 직접 갱신했으며 위키 변경 없음.
