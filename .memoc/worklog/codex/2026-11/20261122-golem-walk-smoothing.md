# 골렘 바깥손 이동 연결 수정

2026-11-22, Codex.

- 사용자 지적: 바깥쪽 손이 움직일 때 부자연스러우므로 자세 사이를 자연스럽게 연결한다.
- 내장 imagegen으로 v1의 골렘 외형을 참고해 4×4의 16개 이동 자세를 다시 그렸다. 주먹 지지 → 몸 당김 → 낮은 회수 곡선 → 착지, 손목/팔꿈치 연결, 마지막→처음 연결을 중심으로 프롬프트를 작성했다. 생성 시트와 포즈를 직접 검토했다.
- `assets/sprites/enemies/stone-crystal-golem-walk-left-v2.png`와 정확한 프롬프트, 프레임별 발 기준점/배율을 가진 JSON, GIF 및 투명 APNG를 저장했다. v1은 변경하지 않았다.
- 12.5fps/80ms×16프레임으로 한 주기는 기존처럼 1.28초다. 미리보기는 v1과 비슷한 표시 크기로 인코딩했다. 원본 아트 픽셀은 보존하며 정렬·인코딩만 수행했다.
- 16개 프레임 비중복·투명 배경·셀 내부 여백·미리보기 디코딩/재생시간을 검증했다. 기존 Animation에서 16프레임×좌우 반전 SDL software 렌더 및 프레임 중앙 시점의 2회 반복·주기 경계를 확인했다. 런타임 코드는 변경하지 않았다.
