# 전투방의 적과 수정탄 시야 개선

2026년 11월 23일. HK-GP05의 전투 여백, HK-GP37의 투사체 대비, SS-HH-06의 어두운 둘레와 전경 배치를 참고했다. 폐아치와 숲 원경을 약하게 누르고, 우측 상단 조명은 수정탄 비행 높이 위로 올렸다. 바닥 뒤에는 넓은 여광을 두고 포자 수와 밝기를 낮췄다. 천장에 고정된 덩굴과 뿌리를 짧게 그렸다. 기존 발판 3개와 골렘 2마리, 공벌레 2마리의 배치 및 충돌과 하강 접근 동작을 유지했다.

실제 골렘 발사 코드에서 나온 두 수정탄을 같은 위치와 카메라로 렌더링해 비교했다. 높은 발판 시점도 시각 검수했다. 동일한 하강 노출 상태에서 지면 아래 픽셀이 일치했다. 전체 테스트 179개, Python 컴파일, 문서 링크와 Git diff 검사를 통과했다. 장시간 수동 조작과 실기기별 성능 검증은 남아 있다.

`AGENTS.md`에 이미지 생성 전에 통합 자료에서 참고 이미지를 확인하고 참고 ID와 반영 원리를 프롬프트 또는 메타데이터에 함께 기록하도록 추가했다. memoc 실행에는 npx가 필요해 이번 작업은 저장소 메모리에 직접 기록했다.
