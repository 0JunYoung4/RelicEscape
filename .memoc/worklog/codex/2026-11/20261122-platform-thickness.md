# 돌 발판 세로 두께 복원

2026-11-22, Codex.

- 사용자가 발판을 세로로 납작하게 줄일 필요가 없다고 정정했다. 세 발판 모두 기존 통로 발판과 같은 두께 90으로 복원했다. 가로 폭과 윗면 높이는 유지한다.
- 좌우는 y100~190, 중앙은 y180~270이다. 두꺼워진 좌측 발판이 문 출구를 막지 않도록 양쪽 발판을 벽에서 100만큼 띄웠다. 이미지와 물리 bounds는 동일하게 유지한다.
- 기존 전투방 검사 8개 통과. 단단한 발판 아래로 걷는 것을 가정하던 바닥/벽 검사 위치만 보정했다. 문 출구에서 왼쪽 발판으로 실제 점프 도달을 추가 실행으로 확인하고, SDL 렌더에서 세 발판의 복원된 두께와 중앙 기립 자세를 직접 검토했다. 코드 변경은 지형 bounds에 한정한다.
