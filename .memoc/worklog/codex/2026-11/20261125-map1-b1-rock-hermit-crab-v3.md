# B1 바위 소라게 외형 v3

- 내장 ImageGen으로 기존 조립 자세를 수정 골렘과 같은 회청색 바위, 짙은 돌 틈, 올리브색 이끼의 픽셀 아트로 다시 그렸다. 기본 자세의 집게와 은신 시 드러나는 두 수정을 유지했다.
- [비교 시안](../../../../assets/concepts/b1-hermit-crab/assembled-preview-v3.png)에 기존 동굴 배경과 바닥을 사용해 두 자세를 합성했다. 같은 폴더에 자세별 투명 PNG와 편집 프롬프트를 두었다.
- 외형 시안 작업이며 게임 렌더러와 동작 코드는 이 작업의 범위에 포함하지 않았다.
