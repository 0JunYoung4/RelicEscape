# 수정 바위 골렘 기본 이미지와 주먹 이동 애니메이션

2026-11-22, Codex.

- 사용자 요청: 콘셉트에 따라 기본 이미지를 만들고 이동하는 애니메이션까지 제작한다.
- 내장 imagegen으로 콘셉트 v1을 따르는 투명 기본 PNG와 해당 기본 이미지를 참고한 4×2 이동 시트(8프레임)를 생성했다. 모두 `assets/sprites/enemies/stone-crystal-golem-{idle,walk}-left-v1.png`에 저장하고 정확한 프롬프트를 보관했다.
- 이동 그림은 양 주먹을 번갈아 짚어 몸을 끌고 짧은 뒷다리를 옮기는 동작이다. 생성된 포즈를 직접 검토했다. 팔/손/다리 포즈는 모델이 생성했으며 수작업 변형으로 가짜 프레임을 만들지 않았다.
- 원본 픽셀을 보존한 채 셀을 읽고 발 기준점을 기록했다. 이동 JSON은 셀 384×512, 8프레임, 6.25fps/1.28초 반복, 키 140 기준 배율이다. 보이는 높이 308~311px로 크기 일관성을 확인했다.
- 같은 프레임을 발 정렬하여 GIF 및 투명 APNG 반복 미리보기로 인코딩했다. 8개 서로 다른 프레임·루프·160ms 재생시간·투명 배경·셀 비잘림을 검증했다.
- 기존 player.Animation에서 기본 좌우 2회와 이동 8프레임×좌우 2방향을 실제 SDL software 렌더로 확인하고 2회 주기 인덱스를 검증했다. 런타임 코드 변경은 없으며 맵 배치·공격/피격 로직은 이번 범위에 포함하지 않았다. README에 자산 링크와 로딩 방향을 기록했다.
