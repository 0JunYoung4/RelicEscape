# 공벌레 피격 넉백과 연속 공격 거리

- 사용자 요청: 공벌레를 공격하면 몬스터가 살짝 뒤로 밀리고, 넉백 가능한 작은 몬스터는 연속 공격 중 간격을 확보할 수 있도록 한다.
- 기존에는0.28초 피격 정지와 그림의 흔들림만 있었다. `pillbug.py`에 실제 x 이동을 추가했다. 속도400에서0.12초 동안 선형 감속하여 최대24월드(기본 배율12px) 밀린다.
- 피격 정지 구간 안에서만 밀리며 일반 접근/구르기 시간은 멈춘다. 새 유효 베기에 넉백과 경직 갱신, 기존 swing_id로 같은 베기 중복 차단. 사망과 등장 시 pending 넉백 초기화.
- 현재 자세의 실제 몸체로 벽/월드 경계/지지 발판 경계까지 이동량을 제한한다. 순찰 구간을 현재 위치까지 확장하여 경직 종료 후 원래 위치로 튀는 문제를 예방한다. 기존 구르기·뒤집힘·회복 단계와 플레이어 공격 반동은 유지한다.
- `tests/test_pillbug_knockback.py`: 생존6자세×좌우×30/60/120fps, 중복 타격, 반대쪽 재피격, 벽/양쪽 발판 끝/월드 끝 반복 밀림, 순찰 재개, 사망/등장 초기화5개.
- `tests/test_attack_recoil.py`: 실제 Player가4초간 연속 공격하는 통합 검사. 체력을 높인 공벌레의 순찰/구르기·좌우·30/60/120fps에서8회 이상 명중, 실제 밀림, 몸체 간격20 초과와 접촉 피해 없음 확인.
- 관련39개 통과: 공벌레21·공격반동5·접촉5·골렘8. 컴파일·git diff --check 통과. 실제 SDL의 연속 타격→사망2.5초 GIF 및4장 연락표 검토. `docs/pillbug-hit-knockback.gif`, `docs/pillbug-hit-knockback-preview.png`.
- 장시간 수동 조작의 밸런스 체감은 미검증. README에 동작/확인 GIF를 기록했다. memoc 런타임/npx 부재로 프로젝트 기록은 직접 최소 갱신했으며 위키는 변경하지 않았다.
