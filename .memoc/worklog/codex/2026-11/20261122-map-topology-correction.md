# 첫 구간과 중앙 통로 연결 정정

2026-11-22, Codex.

- 사용자가 첨부한 첫 구간 상세 지도를 우선하도록 정정했다. 원본은 `docs/first-boss-map-plan-reference-v1.png`와 `docs/world-map-plan-reference-v1.png`에 보관한다.
- 추락 구멍은 문양 바로 앞에 생긴다. 중앙 통로는 여러 지하 구역의 허브이며 시작 동굴과 직접 연결되지 않는다.
- 첫 구간 구상은 깨어나는 방 → 오른쪽 학습/이끼 통로 → 하단으로 이동 → 왼쪽 B1 → 오른쪽 봉인문이다. B1 이후는 미구현이다.
- 기존 진행 지도 v1의 연결 오류를 바로잡은 `docs/world-map-progress-2026-11-22-v2.png`를 내장 이미지 생성 도구로 제작·저장했다. 생성 이미지를 직접 확인해 문양 앞 낙하 위치와 중앙 통로의 시작 동굴 비연결, 첫 구간 상세 동선을 검토했다. 게임 코드 변경은 없다.
- 사용자가 v2의 전체 구조를 향후 맵 제작 기준으로 확정했다. 구역 배치·연결을 따르고 세부 지형은 제작 시 조정한다. 제작 예정 구역을 구현 완료로 취급하지 않는다.
