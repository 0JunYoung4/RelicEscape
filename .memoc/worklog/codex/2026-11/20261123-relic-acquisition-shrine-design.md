# 첫 유물 획득 구조물 디자인 v1

- 사용자 요청: 유물을 획득하는 부분에 있을 구조물 디자인.
- 결과: 이끼와 덩굴에 잠식된 파손 육각 봉인석과 낮은 받침대. 프로젝트의 실제 순간이동 문양과 승인 기둥의 손그림 돌·식생 표현을 내장 imagegen의 참고로 사용했다.
- 중앙은 투명한 빈 공간, 받침대는 낮게 유지하고 윗부분을 비대칭으로 부쉈다. 장착부는 잎으로 가리지 않는다. PNG에는 유물과 발광을 합치지 않았다.
- `assets/concepts/relic-acquisition-shrine-v1*`: 생성 원본, 투명 크롭PNG, 정확한 프롬프트, JSON. 크롭50/60/1375/1048, 기준점662/974, 미리보기 높이380월드·기존 유물 높이100.
- `tools/preview_relic_shrine.py`: 공통 MossCaveArt/실제 Player/유물로 배치 시안을 렌더. 기본0.5·확대0.8 SDL2장을 `docs/relic-acquisition-shrine-v1-{gallery,closeup}.png`로 저장했다.
- 검증: 알파0~255 및 중앙 구멍 투명 확인, 원본 복사/크롭 픽셀 일치, SDL2장 시각 검토, 컴파일·git diff --check 통과. 실행 게임 배치·충돌·획득 코드는 수정하지 않았으며 게임 테스트를 추가 실행할 변경은 없다.
- 상태: 디자인 시안 전달 완료. 사용자 승인이나 게임 적용 요청으로 간주하지 않는다. 자산/메타데이터와 미리보기 재생성 방법은 `docs/environment-art-direction.md`에 기록했다.
- memoc 런타임/npx 부재로 최소 메모리/작업 기록을 직접 갱신. 위키 변경 없음.
