# 맵 천장 덩굴 고정과 캐릭터 카메라

- 사용자 요청: 화면 위 덩굴 그림자를 맵 천장에 두고 화면은 캐릭터 위치를 따라가게 한다.
- 원인: draw_canopy의 기본값은 화면 상단 고정, 전투방은 천장이 화면높이1.2배 안에 들어오는 순간 월드 기준으로 전환했다. 배치가 급변할 수 있었고 가로 방향도1.04배 시차였다.
- `moss_art.py`: roof 인자 필수, 월드 폭1120으로 고정, 천장+30에 스트립 상단 배치, 천장 위 검은 바위 채움. 메시의 최대19월드 아래 윤곽까지 화면 밖 제거 범위에 포함.
- `lower_caves.py`: 통로 천장900(기존 포자 상단)과 전투방 실제 천장을 사용. 두 구간 모두 캐릭터 높이 추적, 천장 표시를 위한 카메라 상한 제거. 지상 발 위치20~40% 및 기존 하강 추적 유지. 시작 동굴/최초 착지방/물리 지형은 보존.
- 회귀4개: 가로·세로 카메라 이동 후 같은 월드 지점 픽셀 비교, 천장 화면 밖일 때 상단 장식 없음, 이전 전환 임계점 통과 시 급변 없음, 캐릭터 높이 추적. SDL 삼각형 가장자리 샘플 오차 허용치 평균0.02채널 미만.
- 검증22개 통과: 위4개, 전투방9개, 클리어7개, 유물 시작2개. 컴파일·git diff --check 통과. 실제 SDL 통로 지상/발판·전투방 지상/상승4장과 비교 GIF 검토. `docs/ceiling-vines-*`.
- 장시간 수동 플레이 및 별도의 실제 좌표 순간이동 재현은 하지 않았다. 확인한 수정 범위는 화면 기준 배치 전환과 카메라 추적이다.
- memoc 래퍼는 npx 부재로 사용 불가하여 관련 메모리만 직접 갱신했다. 위키 변경 없음.
