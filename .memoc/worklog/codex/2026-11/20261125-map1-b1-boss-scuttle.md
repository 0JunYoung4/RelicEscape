# B1 바위 소라게 좌우 이동 시안

- `assembled-upright-v6.png`의 외형으로 짧은 네 다리를 번갈아 딛는 옆걸음을 제작했다. 이동하는 쪽 집게를 낮추고 체중이 실리는 박자에 등딱지를 조금 기울인다.
- `boss-scuttle-preview-v1.gif`는 둥지 양쪽에서 플레이어에게 접근하는 동작을 보여준다. `boss-scuttle-poses-v1.png`는 투명 8열 × 4행 시트다. 셀은 616 × 410, 바닥 기준점은 (308, 382)다. 위 두 행은 오른쪽, 아래 두 행은 왼쪽 이동이며 각 방향에 16개 프레임을 둔다.
- 후속 패턴 구상은 양쪽에서 접근하는 보스를 플레이어가 공격해 밀어내며 버티고, 보스가 중간에 기존 점프 낙하로 전환하는 흐름이다. 이번 작업은 이동 모션 시안이다.
- 빠른 접근 요청을 반영한 `boss-scuttle-preview-v2.gif`는 각 방향의 이동 프레임을 40ms에서 20ms로 줄였다. 방향당 이동 구간은 1.12초이며 기존 자세와 전환 구간의 프레임을 확인했다.
