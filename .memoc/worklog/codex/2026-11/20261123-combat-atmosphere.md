# 전투방의 깊이와 조명 개선

2026년11월23일. 녹색 거리 조사와 현재 맵 비교 이후 사용자가 전투방부터 개선하도록 요청했다.

## 구현

- 내장 imagegen으로 `green-combat-midground-ruins-v1.png`(1536×1024)와 `green-combat-foreground-roots-v1.png`(1024×1536)를 생성했다. 원본 RGBA 자체를 사용하고 정확한 프롬프트·용도 JSON을 `assets/terrain/`에 보관했다.
- `combat_scenery.py`: 낮은 대비의 뿌리 폐아치, 비대칭 배경 명암, 부드러운 사선 광막·대기광, 천장 고정 전경. 지면 아래 누출 방지와 호출자 클립/블렌드 복원.
- `moss_art.py`: 선택 배경 색조의 이전값 복원, CombatScenery 지연 로드, 포자 개수 인자(기본32).
- `lower_caves.py`: 전투방에만 색조126/167/188·새중경/광막/전경·포자18개 적용.
- `tools/preview_combat_atmosphere.py`: 실제 게임 렌더러의 4개 시점 PNG와 카메라 GIF 재생성. 비교 이미지 `docs/combat-atmosphere-comparison.jpg`.

## 검증

기존 전투/카메라/덮개/하강/출입구/트리거32개와 새 렌더 회귀4개, 총36개 고유 검사 통과. 처음 묶음35개(107.688초), 최종 새4개(2.932초)를 확인했다. 컴파일·git diff --check 통과.

SDL 소프트웨어 렌더의 지상/적4마리/상단/하강4장과 전후 비교를 직접 열어 검토했다. 첫 결과의 중경 대비를 낮추고 전경의 천장 위 사각 잘림을 가렸다. 명암은 낮은 입구 배경까지 확장해 수직 이음새를 없앴다. 새 전경이 그려지는 실제 전투방 좌표에서 카메라32px/40px 이동 후 픽셀 정렬 검사도 통과했다. 카메라 GIF33프레임 보관.

기존 발판/적 배치/충돌/덮개112/접근 조명/카메라 및 통로/착지방/시작 동굴은 유지했다. 동시에 진행된 공벌레 넉백과 유물 구조물 시안은 수정하지 않았다. 장시간 수동 키 조작과 실기기별 성능은 미측정.

memoc 런타임/npx 부재로 래퍼 search/work/ingest/lint-wiki를 사용할 수 없어 최소 메모리·작업 로그를 직접 갱신하고 링크를 확인했다.
