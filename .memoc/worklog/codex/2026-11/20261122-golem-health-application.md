# 바위 골렘 HP65 본편 적용

2026-11-22, Codex.

- 사용자 요청: 새 바위 골렘의 체력을 65로 설정해 적용한다. 공벌레 체력30과 주인공 공격력12는 유지했다.
- 골렘이 이미지 자산만 있는 상태였으므로 `crystal_golem.py`를 추가해 HP65·느린 순찰22·몸 판정·베기당1회 피해·피격 표시·처치를 구현했다. 수정 발사 기능은 추가하지 않았다.
- 전투방 좌우에 골렘 두 마리를 배치하고 16프레임 이동v2를 로드했다. 두꺼운 좌우 발판을 관통하지 않도록 중앙 긴 발판 아래의 안전한 순찰 구간을 사용한다. 체력바는 표시하지 않는다.
- 방별 적 목록과 업데이트를 공용으로 연결해 기존 공벌레와 새 골렘 모두 명중 반동/접촉 피해를 받는다. 전투방 재시작 시 적 HP는 복구하고 이미 획득한 유물은 유지한다.
- 회귀 검사5개 추가: 65→53→41→29→17→5→0, 중복/빗나감 방지, 순찰·지형·피격 정지, 실제 전투방 피격/반동/접촉/제거, 사망 후 HP65 및 유물 유지. 전체113개 테스트 통과(41.768초), py_compile 및 diff 검사 통과. SDL 실제 적용 화면에서 두 골렘 크기와 바닥 배치를 직접 확인했다.
