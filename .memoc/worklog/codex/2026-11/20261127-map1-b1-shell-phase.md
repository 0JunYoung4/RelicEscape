# B1 보스 체력과 50% 은신 기믹

- 기본 베기가 회복 중의 보스에 한 번만 명중하고 절반에서 멈춘다. 행동트리는 현재 공격 완료 뒤 중앙 집게 한 번과 등딱지 은신을 이어간다.
- 두 수직 레일에 기존 유물 장착·베기·이동을 사용한다. 중앙 천장 바위를 실제 베기로 떨어뜨리면 별도 파쇄 애니메이션과 재등장이 진행된다. 바닥 복귀부터 1.20초 반격 시간을 잰다.
- 실게임 입력으로 양쪽 레일에 각각 올라가 바위를 내려뜨리고 교전을 재개했다. [조작과 행동트리](../../../../docs/b1-hermit-crab-combat-design.md#기본-교전-조작-테스트)
- Direct3D 11에서 기본 베기 4회로 96→48, 중앙 집게 1회, 좌우 레일 각각의 왕복과 파쇄를 확인했다. B1 관련 12개와 전체 회귀 테스트 241개가 통과했고 이전 포효 테스트 화면은 픽셀 단위로 일치했다.
