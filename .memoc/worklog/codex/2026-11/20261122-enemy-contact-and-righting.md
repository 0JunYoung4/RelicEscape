# 공벌레 접촉 피해와 기립 복구

2026-11-22, Codex.

- 사용자 요청에 따라 모든 살아 있는 공벌레 자세에 몸 접촉 피해 10을 적용했다. 0.8초 동안 여러 적의 반복 접촉을 함께 차단한다. 사망한 적은 제외하고, 구르기가 플레이어 표면에서 멈추는 접점도 판정한다.
- 본편 피격 색상·입자·HP 표시 및 사망 암전을 연결했다. 사망 시 현재 이끼 통로를 체력 100·새 몬스터·획득 전 유물로 재시작한다. R은 기존 동굴 재시작에 체력 초기화를 추가했다.
- 뒤집힘 1.25초 후 기존 자세를 역으로 사용해 0.52초 동안 기립한다. 순찰 후 0.65초가 지나면 재공격 가능하다. 발판 양끝에서 몸 전체 지지를 보장하며, 돌진 후 순찰 범위를 현재 위치까지 확장해 순간 이동을 방지한다.
- 회귀 검사 8개 추가(접촉 5, 기립 3), 기존 영구 뒤집힘 기대 검사를 새 규칙으로 수정했다. 전체 100개 검사 통과(37.603초), SDL software 렌더에서 좌우 기립 5단계·순찰 자세를 직접 검토했다.
- 최초 전체 검사에서 SDL texture 수명 오류 1건이 발생했다. 새 테스트가 mock 호출 기록에 붙잡은 게임 텍스처를 캔버스 종료 전에 해제하도록 수정한 뒤 전체 통과했다. 게임 조작감에 대한 직접 플레이 평가는 하지 않았다.
