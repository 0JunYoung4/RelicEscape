# 골렘 죽음과 피격 경직 제거

2026-11-22, Codex.

- 사용자 지정: 골렘은 덩치 때문에 피격 모션/경직이 없다. 기존 hurt_remaining·피격 색 변화·명중 시 충전 취소/쿨다운 리셋을 제거했다. 비치명 명중은 HP와 swing_id만 갱신해 이동과 공격 타이밍을 유지한다. 공통5종 기준의 의도적인 예외로4종을 사용한다.
- 내장 imagegen으로 큰 주먹과 팔이 버티다 머리/몸통/등 수정이 돌무더기로 낮게 무너지는16프레임을 제작했다. 붕괴1.28초+푸른 픽셀0.72초, 총2초. PNG/JSON/정확한 프롬프트 보존, 접지/크기/알파 셀 분석만 후처리.
- 치명타는 phase=death/death_time=0으로 행동/접촉/추가피격/예약 발사를 중단한다. 기존 투사체는 계속 움직인다. 푸른 소멸은 death_pixels.py를 공벌레와 공유하도록 추출했고 공벌레 기존 효과와 경직은 유지한다.
- 죽음 원본 높이140, 최종 돌무더기162셀을 실제 실루엣에 맞춰 사각 픽셀로 렌더한다. 전멸 HP0 정책 유지.
- 기존 검사에서 맞으면 멈춤/충전 취소 기대를 새 요구로 수정했다. 신규4개는 발사 직전 비치명 타격의 조준/타이밍 유지,30/60/120fps6타죽음·정지·무해·부활 금지, 붕괴→다수푸른픽셀→제거, 실제검6회와주인공반동/골렘정지없음/죽음 렌더를 검증했다. 기존 관련28개·새4개·전체150개 통과. py_compile·git diff --check 통과.
