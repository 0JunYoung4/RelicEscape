# 전투방 좌우 발판과 높은 긴 중앙 발판

2026-11-22, Codex.

- 사용자 최신 요청대로 왼쪽·오른쪽에 각각 하나, 그보다 조금 높은 중앙에 가로로 긴 발판 하나를 배치했다. 현재 총 3개가 배치 기준이다.
- 좌우는 폭 280, 충돌 높이 158~190이며 벽에 붙인다. 중앙은 폭 560, 높이 230~270이며 실제 방 내부 중앙에 맞춘다. 좌우 발판 아래로 서서 문을 통과할 수 있도록 머리 공간을 확보했다.
- 기존 투명 `moss-gallery-small-platform.png`를 재사용했다. 배경 PNG는 변경하지 않고 `COMBAT_PLATFORMS`의 같은 bounds를 렌더와 충돌에 사용한다.
- 각 발판 착지 및 바닥→좌측→중앙→우측 점프 도달 회귀 검사 2개 추가, 기존 바닥 검사를 발판 사이 공간으로 이동했다. 전체 108개 테스트 통과(43.449초), diff 검사 통과. SDL 실제 배치·캐릭터 중앙 발판 기립 화면을 직접 확인했다.
- 몬스터 추가 및 전멸 후 개방은 미구현 상태를 유지했다.
