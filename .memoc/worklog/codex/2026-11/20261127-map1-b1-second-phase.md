# B1 바위 소라게 2페이즈 연속 낙하

- 천장 바위로 은신을 풀고 전투 바닥에 복귀하면 기존 얼굴 노출을 거쳐 2페이즈에 들어간다.
- 행동트리는 2연속 낙하 → 집게 → 단발 낙하 → 집게를 반복한다. 연속 낙하의 두 목표는 각 예고에서 고정하고, 마지막 착지에서 1.25초 동안 반격이 가능하다. [공격 순서와 조작](../../../../docs/b1-hermit-crab-combat-design.md#기본-교전-행동트리)
- 양쪽 레일과 2페이즈 진입, 두 착지의 피해 및 반격, 패턴 반복을 검증했다. B1 테스트 14개와 전체 테스트 243개가 통과했다. SDL로 재등장과 두 낙하의 예고·착지를 확인했다. 도입과 1페이즈 정지 화면 10장은 이전 버전과 일치했다.
