# C파트 석벽 전실과 B 연결 적용

- 내장 ImageGen으로 A·B 재질의 배경·중경·전경을 각각 제작했다. 문·석등·기존 지형 원화와 공벌레 배치·기능을 유지했다.
- B와 C 배경을 지형 전에 그리는 순서로 정리했다. B 석벽 위에서 C 석벽이 x0~690으로 사라진다. 옛 C 원경 비석·아치·광막은 교체했다.
- 큰 석재·얕은 벽감·부조·아래쪽 전경으로 겹침을 정리했다. 균열빛은 y590에서 멈추고 표면 반사광과 연결하며, 석등 청색은 기존 활성 조건을 따른다.
