# B1 소라게 보스전 본편 연결

- C 석등을 켜면 왼쪽 아치가 열리고, 바닥에서 문 쪽으로 걸으면 B1 방으로 넘어간다. `E` 조사 뒤 진동과 포효가 재생되고 기존 보스 행동트리가 시작된다.
- 본편의 플레이어·체력·유물 상태를 사용한다. 사망하면 암전 뒤 C 석등에서 다시 시작한다. 격파하면 오른쪽 석문이 열려 C 전실로 돌아가고 같은 플레이 동안 격파 상태를 유지한다. [본편 진행과 재도전](../../../../docs/b1-hermit-crab-combat-design.md#본편-진행과-재도전)
- C 테스트 8개에서 전실 이동과 재도전, 배경 연결을 확인했다. SDL에서 기존 석조 아치의 닫힘·열림을 각각 확인하고 바닥 접근 판정과 C 복귀 위치를 실제 플레이어 이동으로 검사했다.
- 본편 SDL에서 C 입장, 유물 복귀, 피격 사망과 석등 재도전, 레일과 바위 타격, 2페이즈, 격파 후 출구 통과와 재입장을 검증했다. 레일 상승 후 `Q` 복귀는 2.99초와 3.01초 조건으로 확인했다. B1·C 관련 테스트 23개가 통과했다.
- 전체 244개 테스트가 통과했다. 본편 SDL 화면에서 석등 앞 입구, 포효, 은신, 두 낙하의 예고, 격파 후 오른쪽 통로를 확인했다. 독립판 정지 화면 10장은 이전 버전과 픽셀 단위로 일치했다.
