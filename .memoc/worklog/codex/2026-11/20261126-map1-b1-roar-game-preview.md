# B1 포효 게임 테스트 장면

- 독립 장면에서 기존 둥지 원화의 원경·지형과 전경 사이에 v4 포효와 기존 파동·먼지 효과를 실제 SDL 텍스처로 그린다. `Player`, `Camera`, `Animation`을 사용하고 포효 정점에 주인공이 몸을 낮춘다.
- 실제 SDL 프레임버퍼에서 캡처한 960 × 540 무손실 WebP와 `E`/`R`로 다시 볼 수 있는 실행 명령을 [포효 자산 문서](../../../../assets/concepts/b1-hermit-crab/roar-v4/README.md)에 기록했다.
- 스크립트 컴파일, SDL 시간별 재생과 캡처, WebP의 2초 동작 및 끝 자세 유지, C 전실 회귀 검사 5개를 확인했다. 본편 B1 입장과 전투 연결은 후속 작업이다.
