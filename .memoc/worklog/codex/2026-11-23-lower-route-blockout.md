# 하단 동선 사각형 레벨디자인

- 사용자가 상세 미술 대신 사각형 구조도, 유물 사용, 기존 공벌레·수정 골렘과 방패병 배치를 요청했다.
- `docs/map1-lower-route-blockout-v1.{png,md}`와 재생성 도구를 추가했다. 오른쪽 착지→유물 필수 하부 스위치/복귀→혼합 전투→안전 전실→왼쪽 B1.
- 유물은 하나이며 A/B/C는 설치 후보 위치. 상부에 남긴 유물로만 빠져나오는 하부 스위치실과 낙하구 연동은 제안이다. 방패병 방향 전환·후면 공격도 미구현 동작 제안이다.
- 사각형만 사용하는 PNG를 렌더링하고 문자·배치·진행 방향을 시각 검토했다. 진행문은 천장까지 막아 점프 우회를 방지한다. 실제 플레이 검증은 하지 않았다. 게임 소스 변경 없음.
