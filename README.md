# RelicEscape

귀환 지점을 설치하는 유물과 소모성 순간이동 파편으로, 함정과 몬스터가 가득한 유적을 탈출하는 2D 탐험 액션 게임.

## 프로젝트 상태

- 현재 단계: 초기 기획 v0.1 (2026-10-31)
- 게임 제목: RelicEscape (가칭)
- 개발 예정 환경: Python, pico2D
- 플레이 방식: 2D 횡스크롤 탐험, 액션, 가벼운 퍼즐
- 목표 실행 환경: 데스크톱과 노트북
- 현재 저장소에는 기획 문서만 있으며, 실행 가능한 게임 코드는 아직 없습니다.

## 핵심 플레이

1. 주변 지형과 위험을 관찰하고 귀환 지점을 남깁니다.
2. 유적을 탐험하며 함정과 몬스터를 통과합니다.
3. 필요한 순간에 투척형 순간이동 아이템으로 먼 곳이나 유리한 위치에 진입합니다.
4. 아이템을 얻거나 장치를 작동시킨 뒤, 귀환 능력으로 복귀합니다.
5. 열린 길과 새 통로를 따라 출구로 향합니다.

## 개발 및 실행 준비

첫 실행 버전을 만들 때 사용할 Python과 pico2D 버전을 정하고, 의존성 목록과 설치·실행 방법을 추가할 예정입니다. 이미지·소리·맵은 프로젝트 기준 경로로 관리하고, 가상환경은 각 컴퓨터에서 따로 생성합니다.

개발은 기능 단위로 실행을 확인한 뒤 커밋합니다. 다른 컴퓨터에서 이어서 작업할 수 있도록 작업 종료 시 GitHub에 변경 내용을 푸시하고, 작업 시작 시 최신 내용을 받습니다.
