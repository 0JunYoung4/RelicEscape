# RelicEscape

땅이나 유적의 특수장치에 설치한 유물의 현재 위치로 순간이동하며, 함정과 몬스터가 있는 유적을 탐험하고 탈출하는 2D 횡스크롤 액션 게임.

## 프로젝트 상태

- 기획 버전: v1.1 (2026-11-03)
- 제목: RelicEscape (가칭)
- 개발 환경: Python, pico2D
- 개발 기간: 약 4주 (11월 3~30일), 12월 1~6일 최종 검증
- 발표 예정: 12월 둘째 주, 정확한 날짜 미정
- 구성: 동굴 오프닝 → 작은 튜토리얼 스테이지 1개 → 메인 스테이지 1개 → 마지막 보스전 → 종료
- 목표 실행 환경: 데스크톱과 노트북
- 현재 단계: 횡스크롤 이동 프로토타입. 걷기·달리기·숙이기·기어가기, 지형 충돌·벽 슬라이드·벽점프와 추적 카메라를 구현했습니다.

## 주인공

탐험과 새로운 발견을 즐기는 16~19세의 오른손잡이입니다. 덩굴과 풀을 자르는 탐험 도구인 정글도를 전투에도 사용합니다. 유물은 주머니에 보관하며, 사용할 때 꺼내고 순간이동으로 회수하면 다시 휴대 중에는 보이지 않게 표현합니다.

## 오프닝

유적 조사가 취미인 주인공이 낯선 동굴에 들어가 문양이 새겨진 벽을 발견합니다. 플레이어가 접근해 상호작용 키를 누르면 바닥이 무너집니다. 추락하고 유적에서 깨어나는 과정은 조작 없는 애니메이션으로 보여주며, 각성 이후부터 다시 직접 탐험합니다.

문양을 조사하기 전에 동굴 밖으로 나가면 히든 엔딩으로 이어집니다.

## 핵심 플레이

- 유물을 땅 위에 설치하고 필요할 때 해당 위치로 순간이동합니다.
- 유물을 발사 장치나 레일 장치에 장착해 먼저 이동시킬 수 있습니다.
- 유물이 날아가거나 레일을 이동하는 중간에도 순간이동할 수 있습니다.
- 순간이동하면 유물을 자동 회수하고, 플레이어의 가로·세로 속도를 0으로 초기화합니다.
- 벽에 붙어 천천히 내려오는 벽 슬라이드와 벽점프를 사용합니다.
- 정글도의 일반 공격·점프 공격·내려찍기를 유물과 조합합니다.
- 소모성 투척 순간이동 아이템은 사용하지 않습니다.


## 체력과 성장

기본 체력은 100이며, 체력 강화용 유물 3개를 모으면 최대 체력이 20 증가한다. 낙하 피해는 없다. 가시에 닿으면 체력 25가 감소하고 최근에 밟은 안전한 발판에서 다시 진행한다. 체력 0 처리와 강화 시 현재 체력 회복 여부 등은 추가로 정한다.

## 개발 및 실행

Windows, Python 3.13과 pico2D 1.5.1을 기준으로 준비했습니다. `RelicEscape` 폴더에서 PowerShell로 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

가상환경 활성화 없이 위 명령으로 실행할 수 있습니다. 자산은 코드 파일 기준 경로로 읽으며, 가상환경은 컴퓨터마다 생성합니다.

| 입력 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 걷기 |
| 이동 중 왼쪽·오른쪽 Shift | 달리기 |
| Space | 지상 점프 / 공중에서 벽에 접촉 중이면 벽점프 |
| 공중에서 벽 쪽 방향키 유지 | 하강 시 벽 슬라이드 |
| S 또는 ↓ 누르기 유지 | 몸 숙이기·낮은 자세 유지 |
| S / ↓ 놓기 | 일어서기 |
| Ctrl + H | 캐릭터·지형 히트박스 표시 켜기 / 끄기 |
| F11 | 전체화면 / 1280×720 창 모드 전환 |
| 이동 키 놓기 | 대기 |
| Esc 또는 창 닫기 | 종료 |

기본은 모니터 크기에 맞춘 전체화면입니다. F11로 1280×720 창 모드와 전환합니다. 내부 화면 960×540, 카메라 배율 1/3로 월드의 2880×1620 범위를 보여줍니다. 이전 배율 0.5보다 캐릭터·지형은 약 2/3 크기이며, 가로·세로 시야는 각각 1.5배 넓습니다. 출력 크기에 맞춰 확대하고 화면 비율이 다르면 여백을 둡니다. 가로 6400 월드 단위의 시험 공간에서 이동하며 캐릭터가 중앙에 도달하면 카메라가 따라갑니다. 맵 양 끝에서는 카메라가 멈추고, 플레이어도 맵 경계를 넘지 않습니다. 바닥의 임시 줄눈은 월드에 고정되어 스크롤을 확인할 수 있습니다.

왼쪽 위의 조작·상태 텍스트는 제거했습니다. 좌우를 동시에 누르면 멈추고 창이 포커스를 잃으면 좌우 이동과 새 점프 입력을 멈춥니다. 공중에서는 중력이 계속 적용됩니다. 바닥·발판 착지, 벽의 좌우 면과 천장 충돌을 구현했으며 발판에서 걸어 나가면 낙하합니다.

히트박스는 기본적으로 숨겨져 있고 Ctrl+H로 표시를 전환합니다. 캐릭터는 빨간색, 시험 지형은 청록색 테두리입니다. 왼쪽·오른쪽 Ctrl 모두 지원합니다. 몸통 기준 충돌 영역은 서기 40×140, 완전 숙임 100×80 월드 단위이며, 자세 전환에 따라 보간합니다. 같은 영역으로 지형 충돌을 처리하고 이동·점프·횡스크롤에 맞춰 표시합니다. 무기나 이미지의 투명 여백 전체를 감싸지는 않습니다.

시험 맵에는 낮은 시작 발판, 높이가 다른 세로벽 두 개, 오른쪽 공중 발판을 배치했습니다. 먼저 오른쪽으로 이동해 발판에 올라가거나 첫 벽 쪽으로 점프합니다. 공중에서 벽에 닿은 채 벽 쪽 방향키를 유지하면 상승이 끝난 뒤 천천히 내려옵니다. 이때 Space를 누르면 벽 반대쪽 위로 뛰고, 방향키를 놓거나 벽에서 떨어지면 일반 낙하로 돌아갑니다. 벽에 다시 닿으면 같은 벽에서도 반복 벽점프할 수 있습니다.

벽 슬라이드는 높은 손과 아래쪽 발까지 벽이 받쳐 주는 높이에서만 시작합니다. 벽 상단 근처에서 손이 허공에 놓이면 일반 낙하 자세를 사용하며, 내려와 지지 높이가 확보되면 슬라이드로 전환합니다. 이 구간에서도 몸통이 벽에 닿아 있으면 Space 벽점프는 가능합니다. 각 프레임은 손 접점을 벽에 맞추고, 벽 안으로 들어가는 발 부분은 잘라 그립니다.

벽 슬라이드 최대 하강 속도는 120 월드 단위/s입니다. 벽점프는 가로 480·세로 820의 초기 속도를 사용하며, 처음 0.18초는 벽 반대쪽 힘을 유지한 뒤 좌우 조작으로 돌아갑니다. 벽 이동의 조정 가능한 초깃값입니다. 벽 슬라이드는 승인한 `wall-slide-right-draft-v4` 3프레임을 24fps로 한 번 재생한 뒤 마지막 지지 자세를 유지합니다. 벽 반대쪽 아래를 바라보며, 왼쪽 벽에서는 이미지를 반전합니다. 벽에서 떨어지거나 벽점프하면 점프 그림으로 바로 전환하고, 재접촉하면 첫 프레임부터 다시 재생합니다.

대기는 승인된 source-v3 원본, 걷기는 기존 8프레임, 달리기는 기존 16프레임, 점프는 승인한 [8프레임 초안](assets/sprites/player/jump-right-draft-v1.png)을 사용합니다. 각 이미지의 표시 배율과 발 기준점을 맞추며 왼쪽 이동은 오른쪽 이미지를 좌우 반전해 표시합니다. 전용 왼쪽 이미지 제작 전의 임시 표현입니다.

점프는 준비 → 도약 → 상승 → 정점 → 하강 → 착지 준비 → 착지 → 대기 복귀 순서입니다. 상승·하강 속도에 맞춰 자세를 선택하며 시트를 공중에서 반복하지 않습니다. 이동·달리기 중에도 점프할 수 있고 공중 방향 전환도 가능합니다. 점프 높이는 약 203 월드 단위(내부 화면 약 68px), 공중 시간은 약 0.9초이며 조작 체감에 따라 조정할 초깃값입니다.

숙이기는 [빠른 4프레임 정의](assets/sprites/player/crouch-right-fast-v1.json)를 사용해 약 0.15초 동안 몸을 낮춥니다. 기존 1·3·5·8번째 자세를 골라 사용하며, [8프레임 PNG와 JSON 원본](assets/sprites/player/reference/crouch-8frame-v1/)은 별도 보관합니다. 원본 PNG는 수정하지 않고 4프레임 정의에서 해당 영역만 읽습니다. 마지막 자세를 유지하다가 키를 놓으면 진행 지점부터 역순으로 일어섭니다. 숙인 상태에서는 좌우 입력으로 90 월드 단위/s의 느린 이동을 할 수 있으며 Shift를 눌러도 달리지 않습니다. 공중에서는 숙이기를 시작하지 않고, 숙임·일어서기 중에는 점프하지 않습니다.

완전히 숙인 뒤 좌우로 이동하면 다리 교차 자세를 수정한 [기어가기 8프레임 초안 v2](assets/sprites/player/crawl-right-draft-v2.png)를 초당 8프레임으로 반복 재생합니다. 멈추거나 지형·맵 끝에 막히면 숙인 대기로 돌아갑니다. 숙이기 키를 놓으면 4프레임을 역순 재생해 일어나며, 벽·천장과 겹치는 자세 변경은 공간이 확보될 때까지 보류합니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

위 검사는 창을 띄우지 않고 점프 물리·프레임 순서·공중 재점프 방지·착지 후 이동 복귀, 숙이기 정방향·유지·역방향·입력·느린 이동과 좌우 렌더링을 확인합니다.

기능 단위로 동작을 확인하고 커밋합니다. 작업 종료 시 GitHub에 푸시하고, 다른 컴퓨터에서 시작할 때 최신 내용을 받습니다.

## 시각적 방향

전체적으로 픽셀 아트를 사용한다. 맵은 어두운 고대 지하 유적 분위기로 구성하고, 주인공과 유물은 맵 밝기와 관계없이 잘 보이도록 한다.

유물 초안은 청록색으로 빛나는 문양과 테두리가 있는 정육각형 돌판이다. [유물 초안](assets/concepts/relic-draft.png)은 디자인 검토용이며 최종 게임용 스프라이트는 아니다.

주인공 시각 시안: [캐릭터 콘셉트 A/B/C](assets/concepts/character-concepts-v1.png). 하늘색 탐험복, 오른손의 정글도, 휴대 중 숨겨진 유물을 공통 조건으로 비교했고, 이 중 짧은 머리의 A안을 기본 방향으로 선택했다. 내장 이미지 생성 도구로 제작했으며, [생성 프롬프트](assets/concepts/character-concepts-v1.prompt.txt)를 함께 보관한다. 이미지 하단의 소형 캐릭터는 참고용이며 실제 게임용 스프라이트가 아니다.

선택한 A안을 더 굵고 단순한 도트로 정리한 [A안 보완 시안](assets/concepts/character-a-coarse-v1.png)을 추가했다. 산나비를 그래픽 참고 방향으로 두며, 보스는 주인공보다 세밀하게 표현할 예정이다. 보스의 구체적인 디자인과 실제 게임용 원본 해상도는 미정이다. 이 이미지는 콘셉트 검토용이며, [내장 이미지 생성 프롬프트](assets/concepts/character-a-coarse-v1.prompt.txt)를 함께 보관한다.

처음 A안의 [LD 네 방향 이미지](docs/CHARACTER_TURNAROUND.md)는 승인된 캐릭터 콘셉트로 보관한다. 실제 게임 캐릭터는 [concepts의 SD source 이미지](assets/concepts/player-sd-idle-right-source-v3.png)를 수정·변형하며 제작한다. [64×64 투명 대기 스프라이트](docs/PLAYER_SPRITES.md)는 이전 내보내기 참고 자료이며 최종 제작 해상도를 고정하지 않는다. 게임용 얼굴은 작은 눈만 표현하고 코·입은 생략한 무표정이다. 현재 이동 프로토타입은 기본 대기 이미지와 걷기 8프레임·달리기 16프레임·점프 초안 8프레임을 사용하며, 공격 애니메이션은 추후 제작한다.

게임용 캐릭터는 어린 인상을 줄이기 위해 머리 비중을 줄이고 몸통·다리를 늘린 [중간 체형 v3: 코 돌출 제거](assets/concepts/player-sd-idle-right-preview-v3.png)를 추가했다. 이전 참고 내보내기는 [64×64 대기 프레임 v3](assets/sprites/player/idle-right-v3.png)이며 v1은 비교용으로 유지한다.

## 파일 작성 규칙

파일명과 폴더명은 기본적으로 영어로 작성한다. 사용자가 지정한 `발표&기획서/` 하위 폴더와 PPT 파일명은 한글 이름을 유지한다. 기획서와 README의 설명은 한국어로 작성한다. 커밋 메시지는 영어 작성 규칙에서 제외한다. 자세한 지침은 [AGENTS.md](AGENTS.md)를 따른다.
