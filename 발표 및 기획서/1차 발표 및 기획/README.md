# RelicEscape 발표 자료

## 최신 파일

- RelicEscape_Presentation_4Week.pptx: 1차 발표용 7장. 90초 자동 전환과 장별 발표자 노트를 포함한다.
- RelicEscape_Game_Design_4Week.pptx: 상세 기획서 17장. 캐릭터, 유물, 특수장치, 이동과 전투, 체력과 가시 복귀, 스테이지, 4주 개발 계획을 정리했다.
- Presentation_Script_4Week.md: 수정된 장별 시간과 낭독 대본.
- Character_Introduction.png: 기존 LD 콘셉트와 SD 참고 이미지를 함께 보여주는 캐릭터 소개 자료.

이전 원본과 _Updated.pptx는 보관용이다. 현재 발표에는 _4Week.pptx를 사용한다.

## 개발 일정과 발표

개발 기간은 2026년 11월 3~30일 약 4주다. 12월 1~6일에 오류 수정, 균형 조정과 데스크톱·노트북 실행을 검증한다. 발표 예정은 12월 둘째 주이며 정확한 날짜는 미정이다.

발표용 전환 시간은 8초, 12초, 22초, 14초, 14초, 14초, 6초로 합계 90초다. 실제 낭독 시간은 사람마다 다르므로 연습하고 녹화한 영상의 길이를 확인한다. 두 PPT 표지에는 게임공학과 2023184014 박준영을 기재했다. 글꼴은 맑은 고딕이다.

## 반영한 체력 규칙

기본 체력은 100이다. 체력 강화용 유물 3개를 모으면 최대 체력이 20 증가해 첫 강화 시 120이 된다. 낙하 피해는 없고, 가시에 닿으면 체력 25를 잃고 최근에 밟은 안전한 발판에서 다시 진행한다. 체력 0 처리, 강화 시 현재 체력 회복 여부와 반복 강화 여부는 추가로 정한다.

## 캐릭터와 자료 상태

게임 캐릭터 제작 기준 원본은 assets/concepts/player-sd-idle-right-source-v3.png다. 두 PPT의 게임 내 플레이어 이미지도 이 원본으로 교체했다. 표시를 위해 투명 여백만 잘랐으며, 원본 디자인과 픽셀은 유지했다. assets/sprites/player/의 64×64 PNG는 이전 참고 내보내기 자료다. 제작 해상도와 프레임 크기는 구현 과정에서 정한다. LD 네 방향은 콘셉트 자료로 유지한다.

현재 게임용 이미지는 오른쪽 기본 대기 한 프레임이며 이동·공격 애니메이션과 게임 코드는 제작할 예정이다. 유적 배경과 발사·레일 지도는 내장 이미지 생성 도구로 만든 분위기·플레이 예시이며 실제 게임 화면이 아니다. 보스 외형과 세부 패턴 등은 검토 중이다.

## 녹화와 제출

노트북에서 이미지와 글꼴이 정상 표시되는지 확인한 뒤 녹화한다. 발표 가이드의 PPT 분량 및 제출 항목을 참고하되, 실제 발표일과 마감 시각은 최신 e-class 공지에 맞춘다.
