# B1 푸른 에너지 구체 v2

작은 청백색 중심 주위로 굵기와 길이가 다른 푸른 빛의 결 세 갈래가 흐른다. 격파 빛줄기와 유물 광원의 색을 바탕으로 구체 가장자리의 밝기를 부드럽게 낮춘다. B1 보스방에서는 주변 등딱지와 석벽에도 낮은 강도로 빛이 닿는다. [보스방 크기 부유 미리보기](energy-orb-hover.webp)

[투명 스프라이트 시트 PNG](energy-orb-sheet.png)는 512 × 512 RGBA다. 128 × 128 칸 16개를 4 × 4로 배치했다. 왼쪽 위에서 오른쪽으로 읽으며 각 칸의 기준점은 (64, 64)다. 칸당 75ms로 총 1.20초 동안 반복한다. B1 미리보기에서는 v1과 같은 64 × 64 화면 픽셀로 그린다.

`.\.venv\Scripts\python.exe -m tools.render_b1_defeat_orb_v2`로 다시 렌더링한다.
