# B1 포효 · 새로 그린 자세

바위 소라게의 전투 시작 포효를 보스 그림만 담은 9장으로 제작했다. 무게를 낮춰 힘을 모은 뒤 고개를 위로 젖히고 두 집게를 들어 벌린다. 두 작은 눈과 닫힌 얼굴 돌판을 유지한다. 자세가 풀릴 때 두 집게가 차례로 내려온다.

- [보스 단독 투명 WebP](boss-roar-animation.webp)
- [보스 단독 재생 미리보기](boss-roar-preview.gif)
- [투명 PNG 스프라이트 시트](boss-roar-sheet.png)
- [프레임 타이밍·기준점](boss-roar.json)
- [ImageGen 원본](source-atlas.png) · [생성 프롬프트](source-atlas.prompt.txt)

ImageGen으로 각각 다른 자세를 새로 그렸다. 원본에서 각 자세를 잘라 같은 크기의 칸에 담고, 바닥과 몸 중심을 맞추기 위해 픽셀 위치만 옮겼다. 크기 조정이나 형태 변형, 중간 자세 보간을 사용하지 않았다. 시트는 3열 × 3행이며 왼쪽 위부터 읽는다. 각 칸은 540 × 363px이고 공통 바닥 기준점은 (275, 329)이다. 각 자세의 유지 시간을 달리해 총 2초 동안 재생한다.

공기 파동과 먼지·자갈은 [별도 효과 자산](../roar-v1/README.md)에 있다. v2는 보스 단독 시안이고 본편에 아직 연결하지 않았다.
