# B1 푸른 에너지 구체 부유 시안

기존 격파 빛줄기의 푸른색과 부드러운 감쇠를 사용한다. 옅은 후광 안에서 빛이 모였다 풀리고, 안쪽의 밝은 결 두 갈래와 주변의 작은 잔광이 각 프레임에서 흐른다. 보스방 미리보기에는 같은 조명 합성으로 등딱지와 주변 석벽에 은은하게 닿는 빛을 더했다. [16프레임 부유 미리보기](energy-orb-hover.webp)

[투명 스프라이트 시트 PNG](energy-orb-sheet.png)는 4 × 4 배열, 전체 512 × 512 RGBA다. 왼쪽 위에서 시작해 오른쪽으로 읽는다. 각 칸은 128 × 128이며 중심점은 (64, 64)다. 칸당 75ms로 총 1.20초 동안 반복한다. 미리보기에서는 64 × 64로 그린다.

부유 동작을 검토하는 독립 시안이다. `.\.venv\Scripts\python.exe -m tools.render_b1_defeat_orb`로 다시 렌더링한다.
