# B1 푸른 에너지 구체 v3

작은 청백색 구체에서 원형의 푸른빛이 퍼진다. 바깥으로 갈수록 밝기와 불투명도를 부드럽게 낮췄다. 보스방 빛줄기의 푸른색을 바탕으로 주변 등딱지와 석벽에 약한 반사광을 더했다. [보스방 미리보기](energy-orb-hover.webp)

[투명 스프라이트 시트 PNG](energy-orb-sheet.png)는 512 × 512 RGBA다. 4 × 4 배열의 128 × 128 칸을 왼쪽 위부터 오른쪽으로 읽는다. 기준점은 모든 칸에서 (64, 64)이며, 빛의 밝기와 반경이 75ms 간격으로 변한다. 16프레임이 1.20초 동안 반복되고 이동은 본편 연출에서 처리한다.

`.\.venv\Scripts\python.exe -m tools.render_b1_defeat_orb_v3`로 다시 렌더링한다.
