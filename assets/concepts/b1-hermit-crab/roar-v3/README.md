# B1 포효 · 중간 자세 추가

v2의 원화 9장 사이에 새로 그린 중간 자세 11장을 넣었다. 힘을 모으고 고개를 들어 올린 뒤, 한쪽 집게와 반대쪽 집게가 차례로 펼쳐진다. 얼굴의 닫힌 돌판은 그대로다. 포효의 정점은 잠시 유지하고, 집게가 내려오는 과정도 여러 자세로 나눴다.

- [보스 단독 미리보기 GIF](boss-roar-preview.gif)
- [투명 애니메이션 WebP](boss-roar-animation.webp) · [투명 PNG 시트](boss-roar-sheet.png)
- [프레임 위치와 재생 시간](boss-roar.json) · [생성 프롬프트](source-atlases.prompt.txt)

ImageGen으로 만든 중간 자세를 골라 원본 픽셀 그대로 잘랐다. 기존 자세와 새 자세는 540 × 363px 칸의 바닥 기준점 (275, 329)에 맞춰 위치만 옮겼다. 전체 2초 중 0.72초에 포효 정점에 닿는다. 시트는 5열 × 4행이며 왼쪽 위부터 행 순서로 읽는다. JSON에서 원화의 크롭 범위와 배치 위치를 확인할 수 있다.
