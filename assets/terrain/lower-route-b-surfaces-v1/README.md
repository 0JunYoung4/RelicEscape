# B 통로 발판 재질 v1

첫 전투방과 A 통로에 맞춰 기존 B 발판 5종의 표면을 다시 그렸다. 거친 점각·잔금·흰 광물 얼룩을 줄이고 짙은 청록색의 큰 돌 면, 검은 틈, 둥근 잎과 불규칙한 이끼 덩어리로 정리했다.

- 제작: 내장 ImageGen `style-transfer`, 각 원본을 개별 편집한 투명 RGBA PNG. 생성 알파와 원본 출력은 그대로 보존한다.
- [프롬프트·참고 ID](prompts.json): SS-MG-03, HK-GP22의 돌 면·실루엣과 SS-MF-04의 절제된 따뜻한 빛을 참고했다. 프로젝트의 첫 전투방과 B1 전용 발판은 화풍 참고이며 B1 자산은 변경하지 않았다.
- [앵커 명세](manifest.json): 실제 충돌 경계·보행선·벽점프 면은 기존 값을 따른다. 출력 해상도가 1px 바뀐 두 이미지만 원본 비율로 앵커를 환산했다.
- `connected-guard-wall`: 방패병 상단과 오른쪽 수직 벽. `connected-passage`: C 접근 바닥. `spike-bed-pier`: 공벌레 발판과 아래층에 닿는 기둥. `waterworn-sill`: 지하 석대. `root-wedge`: 독립 B 미리보기 입구.

`lower_route_b_art.py`가 이 팩만 읽는다. 공유 원본 `terrain/ruin-platforms`와 A–B 연결 원화, 지형·레일·장치 좌표는 보존했다. 길잡이 석등은 기존 완성 원화를 높이 190 월드 단위로 배치하고, 받침 접촉 그림자·국소 호박빛·상면 반사광을 같은 월드 변환으로 합성한다. 석등은 기존과 같은 안내 장식이다.

수정 전후와 카메라·실행 검증은 [기록](../../../docs/b-passage-surfaces-camera.md)을 참고한다.
