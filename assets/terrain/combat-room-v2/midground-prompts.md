# 전투방 중경 유적 생성 기록

내장 ImageGen에 승인받은 RelicEscape 전투방 시안을 입력했다. 두 PNG는 그림자와 배경이 없는 독립 RGBA 스프라이트다. 기존 원경에 그려진 석조 고리는 원경에서 별도로 사용한다.

- HK-GP07에서 역광으로 중경 석재의 실루엣이 드러나고 원경이 안개 속으로 물러나는 방식을 참고했다. HK-GP05의 분리된 빛줄기는 렌더링에서 구현했다.
- SS-MG-04에서 크기가 다른 이끼 군집과 식생 사이 여백을 참고했다. SS-SH-06의 부드러운 광막과 어두운 그늘은 층별 광량을 정하는 기준으로 삼았다.
