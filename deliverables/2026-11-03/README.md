# RelicEscape 발표 자료

## 파일

- RelicEscape_Presentation.pptx: 1차 발표용 7장. 장별 대본을 발표자 노트에 포함했다.
- RelicEscape_Game_Design.pptx: 상세 기획서 15장. 캐릭터, 유물, 특수장치, 이동과 전투, 스테이지 구성, 개발 계획을 정리했다.
- Character_Introduction.png: 확정된 LD 콘셉트와 SD 기본 이미지를 함께 보여주는 캐릭터 소개 이미지.
- Presentation_Script.md: 장별 시간과 낭독 대본.

## 발표와 녹화

발표용 전환 시간은 8초, 12초, 24초, 16초, 10초, 14초, 6초로 합계 90초다. 저장된 슬라이드 시간을 사용하면 자동으로 넘어간다. 실제 낭독 시간은 사람마다 다르므로 대본을 읽어 연습하고, 녹화한 최종 영상이 정확히 1분 30초인지 확인한다.

발표자 이름과 학번이 필요하면 표지에 추가한다. 파일의 글꼴은 맑은 고딕이다. 이미지와 글꼴이 노트북에서 정상 표시되는지 확인한 뒤 녹화한다.

## 제출

발표 가이드는 발표 PPT 10페이지 이내, 기획 PPT 분량 제한 없음, YouTube 링크와 Git 저장소 주소 제출을 안내한다. 제출 마감은 가이드상 발표 당일 00:01이다. 사용자 계획의 화요일 저녁과 차이가 있을 수 있으므로 실제 e-class 공지의 마감 시각을 확인한다.

## 자료 상태

캐릭터 기본 이미지는 코 돌출을 제거한 idle-right-v3.png를 사용자 승인 기준으로 확정했다. 게임 캐릭터 제작 기준 원본은 assets/concepts/player-sd-idle-right-source-v3.png이며, 이를 수정·변형해 동작을 확장한다. assets/sprites/player/idle-right.png는 이전의 64×64 참고 내보내기 자료다. 실제 제작 해상도와 프레임 크기는 개발 과정에서 정한다. LD 네 방향은 콘셉트 자료로 보관한다. 현재 게임용 이미지는 오른쪽 기본 대기 한 프레임이며 이동·공격 애니메이션과 게임 코드는 제작할 예정이다.

발표 자료의 유적 배경과 발사·레일 지도는 내장 이미지 생성 도구로 만든 분위기·플레이 예시다. 실제 게임 구현 화면이 아니다. 보스 외형과 세부 패턴 등 미정 항목은 기획서에서 구분했다.

GitHub Desktop에서 변경 내용을 검토하고 커밋한 뒤 Push origin으로 업로드한다. 이 작업에서는 파일을 로컬에 저장했으며 GitHub 업로드와 영상 녹화는 수행하지 않았다.
